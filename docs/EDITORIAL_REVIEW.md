# 深写版教学审读记录

本记录区分正文审读、示例运行、软件回归与硬件实测。它不把篇幅或自动测试数量解释为“读者一定掌握”，也不声称人工逐字证明了每一句内容。逐章篇幅对照见 [深写报告](DEPTH_REPORT.md)，各卷作者的执行记录见各卷 `DEPTH_AUDIT.md`。

## 采用的审读问题

一个初学者第一次遇到术语时，能否找到它的含义、使用目的和先修知识？数学推导有没有跳过关键中间值、单位或 shape？代码摘录是否与真实接口相符，连续代码块需要的前置变量是否交代？实现题是否提供可以核对的答案与边界，诊断题是否有能复现的问题？教学简化、CPU 验证和真实设备实验是否分开说明？

篇幅检查只用于发现仍然过短的章。完全重复段落检查只能发现精确重复，不能自动识别空泛文字。以上教学问题仍需结合实际正文、代码和读者练习结果审查。

## 读者反馈怎样变成下一次修订

如果某一段仍然读不懂，请记录章节 ID、具体小节、无法解释的变量或一组失败输入。修订应补上那个推理缺口，必要时增加先修小课、手算轨迹或完整答案，再检查后续引用是否需要同步改变。不能只在章末添加更多术语或外部链接，让读者自行补齐本应由教材承担的讲解。
