## 新增的大块内容

Linux 与编程基础扩展为独立分卷；Agent 的持久化、失败恢复、协议适配、工作流与可靠性成为主线；检索、记忆、知识图谱成为独立卷；每种模型机制有可执行参考和数值对照；框架卷建立可测试的状态／缓存系统；算子卷从地址和布局一直连接到编译与硬件。

本版不以真实部署一个最大的模型作为结业条件。能够从小实现解释机制，再在生产框架中识别和验证它，才能迁移到更大的模型。实际支持范围必须根据运行时版本、模型权重和硬件证据判断。

## 课程完整与验证完整是两件事

课程提供从先修、机制、实现到项目的完整学习路径。真实模型 API、RTX／H100 GPU 和多卡实验需要相应环境，初版构建环境未执行的部分在验证报告中明确列出。不能把“有教学代码”写成“所有设备均实测”，也不能因为没有现场 GPU 就删去需要 GPU 的学习任务。
