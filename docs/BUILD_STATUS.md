# 第一版建设状态

课程版本：1.0.0。建设日期：2026-11-01。

## 已接受的课程目标

1. 读者起点：只会少量 Linux 命令、基本 Git 和一点 Python；必须从计算机与编程基础教起。
2. 完整覆盖 Harness→模型→推理框架→算子→编译器→GPU 的依赖链。
3. 第一版重点深入 Agent（含图、检索、记忆、协议、可靠性）以及框架和算子。
4. 手写原始 Transformer、稠密解码器、MoE、稀疏／线性注意力等可检验实现。
5. 多层练习、参考答案、故障诊断、可运行综合工程和真实开源源码任务。
6. CPU 优先安排基础实验；适用时使用本地 RTX 或共享 H100，GPU 实验限制规模并记录资源。
7. 在指定 GitHub 仓库交付，课程规范和学习记录机制支持后续扩展。

## 实际验证

初版统一验收：374 项自动测试，373 项通过、1 项可选依赖测试跳过；203 条 CPU 离线实验命令通过，6 条因 GPU 或可选依赖而未执行。课程路径、先修关系、本地 Markdown 链接与 Python 语法检查无错误。完整环境与逐项结果见 [验证报告](VALIDATION.md)。

交叉审查后已修复并加入回归的问题包括：副作用执行后的不确定状态、预算边界误覆盖终态、并发上限类型、Outbox 竞争、删除重建后的版本 ABA、极值余弦、线性注意力缩放、Sinkhorn 数值稳定，以及页池引用失败的原子性。这些机制的教学解释与代码一同修订。

本次没有在 Win11／WSL2、RTX 5070 Ti、H100 或多卡上运行 GPU 实验，也没有调用真实付费模型 API。Docker 构建和完整上游框架测试需要相应环境；仓库提供步骤与边界，不把源码阅读或语法检查当成实际部署结果。远端 CI 状态以 GitHub Actions 为准。

## 后续维护的入口

先读取本文件、README、各卷 manifest 与 `docs/VALIDATION.md`。运行 `python tools/course.py check`，再运行与变更相关的测试。发布前运行 `python tools/verify_release.py` 生成新证据。不要根据聊天摘要假定某课或某硬件实验已通过；只有实际运行后才能改变验证状态。

用户从 [第一次学习](START_HERE.md) 进入课程。个人学习进度与实验记录独立保存在本地，不因课程修订自动变成“已掌握”。新内容遵循 [版本规范](../CONTRIBUTING.md)，保留已有课程 ID 和来源快照。
