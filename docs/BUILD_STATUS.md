## 1.1.0 的深写基础

首版已经有大量主题与参考实现，但主章节常只有一两千汉字，初学者仍要自己补齐术语、数学步骤、变量含义和代码之间的联系。这一版对六卷的 98 个主章节以及两个跨卷综合教程逐章重写，将这些隐含前提放回正文。保留 113 个稳定学习单元和 209 个注册实验入口，原有学习进度与命令继续有效。

篇幅不能证明讲解足够好。因此修订同时要求完整手算、关键行解释、可运行反例、分级练习与完整答案，并记录作者执行和独立审读。逐章对照在 [DEPTH_REPORT](DEPTH_REPORT.md)，写作合同在 [DEPTH_STANDARD](DEPTH_STANDARD.md)，实际发现并修复的问题在 [EDITORIAL_REVIEW](EDITORIAL_REVIEW.md)。

## 验证证据与边界

统一软件验收的时间、解释器、测试数量、逐条实验状态与结构检查，以自动生成的 [VALIDATION](VALIDATION.md) 和 [validation.json](validation.json) 为准。各卷 `DEPTH_AUDIT.md` 另外记录正文代码块、手算和专题实验；注册实验执行不能代替正文代码块执行，语法检查也不能代替运行。

独立审读不只检查篇幅。实际发现并修复了巨大整数校验溢出、终态取消被覆盖、轮转请求退出后跳位、缓存主体隔离、运行恢复身份绑定与模型输入权限、独立页审计漏检、K/V 联合置换验收盲点，以及新手环境步骤与示例依赖不明确等问题。没有把篇幅门槛、测试数量或源码阅读称为专家能力证明。

本次编写环境完成 Linux CPU 路径、临时 Git／SQLite、小规模数组、受控子进程、部分本机 HTTP 与 C++ 示例。Win11／WSL2、RTX 5070 Ti、H100、CUDA／Triton、NCCL 多卡、Docker 实际构建和真实付费模型 API 未在本环境执行。对应完整教学步骤与有界实验已经提供；设备性能和上游完整安装结果仍需按各章在目标环境验收。

A15 还在独立 Python 环境安装并实际验证 MCP 2.3.0、LangGraph 1.2.19 和 Agents SDK 0.24.0：进程内工具注册与严格参数、图中断恢复、真实 Runner 的脚本模型工具循环均通过。依赖快照与边界在该卷 DEPTH_AUDIT 中；这些离线 SDK 集成不代表真实模型 API 或完整跨机协议已经验证。

GitHub Actions 的远端运行与本地验证分开记录。CI 配置存在不代表运行成功；实际状态见 [Actions](https://github.com/1464720728/LLM-Full-Stack-Learning/actions)。

## 继续维护的入口
