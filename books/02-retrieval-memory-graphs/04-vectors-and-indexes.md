# R04 向量检索：几何、学习表征与近似搜索

先修：R03、向量点积与平方根。目标是区分“把内容变成向量”“用某个距离比较向量”“用索引加快搜索”三层，并能实现精确搜索作为任何加速实现的正确性基准。本章不要求 GPU。

## 1. 向量是一组有坐标语义的数

假设只有三个词：cache、request、token。可以用它们的计数作为三维向量。文本“cache cache token”对应 `[2,0,1]`，“request token”对应 `[0,1,1]`。这已经是一个向量表示，但它没有自动学会“缓存”和“cache”意思相近。维度有明确词法含义，适合解释词汇重叠。

神经 embedding 模型则通过训练把文本映射到固定维度的数值空间，使训练目标认为相关的文本靠近。维度通常没有可直接命名的语义，向量相近程度来自训练数据和损失函数，不是数学上保证的知识理解。同样维数的两个模型也不一定共享坐标系，不能把 A 模型的文档向量与 B 模型的查询向量直接比较。

如果 embedding 模型有 query/document 不同提示模板，两者必须遵循各自契约。只记录模型名字而漏掉版本、池化方式、归一化、提示词和截断规则，会使复现困难。对长文档，模型可能只编码前一部分；后面关键句在向量中实际上不存在。

## 2. 余弦相似度从手算开始

点积为 `a·b=Σa_i b_i`，长度为 `||a||=sqrt(Σa_i²)`，余弦为 `(a·b)/(||a||||b||)`。取 a=(3,4)、b=(6,8)，点积 50，长度分别 5 和 10，余弦等于 1。b 是 a 的两倍，但方向一致，所以余弦忽略整体缩放。

a=(1,0)、b=(0,1) 余弦为 0；a=(1,0)、b=(-1,0) 余弦为 -1。词频向量非负，因此它们的余弦不会小于零；神经向量通常允许负坐标。零向量没有定义良好的方向，本课程约定返回 0，并在检索时不把零分结果当命中。真实服务还应记录出现零向量的原因，可能是空文本、预处理错误或模型失败。

单位向量满足 `||x-y||²=2-2(x·y)`，所以对归一化向量，最大点积与最小欧氏距离会产生相同排序。没有归一化时不成立。模型若是按点积训练，擅自归一化也可能改变它原本使用的长度信号，应先看模型说明和评测。

## 3. 本卷为何用 TF-IDF 而不假装有语义模型

`TfidfVectors` 给词频一个 `1+ln(tf)` 权重，再乘平滑 IDF。它返回稀疏字典：仅存非零词维度，而不创建一个几十万维的密集数组。`cosine` 遍历一个字典的非零坐标做点积，因此你可以逐项检查它。

这段实现是“向量接口与精确相似度”的参考，不是现代 dense embedding 的替代品。它与 BM25 都利用词法特征，两者融合未必带来真实语义召回收益。课程明确保留这个限制，以免在玩具语料上得到漂亮结果后误判生产能力。

要换成真实语义模型，应保留上层 `text -> vector` 接口和检索评测，只替换编码器。先用十条材料打印输入与输出形状，检查向量维数、有限值、零范数与重复输入一致性，再做批量生成。模型 API 可以完成 embedding，但要单独确认模型确实提供 embedding 接口；聊天 API 返回文本不是合法的向量编码器替代。

## 4. 精确搜索是一把测量尺

有 N 个 d 维向量，暴力搜索计算 N 次距离，复杂度约 O(Nd)。当 N 小时，这很直接可靠；如果每向量 float32，原始向量数据大约占 `4Nd` 字节，不包含 ID、元数据、索引结构和运行时副本。100 万个 768 维 float32 向量约 3.072 GB 十进制；这只是算存储的起点。

近似最近邻 ANN 用额外结构减少每次检查的候选。IVF 把向量分到粗聚类中，查询只检查若干簇；HNSW 使用分层邻近图，引导搜索走向较近区域；PQ 把向量分段并编码，降低存储和距离计算开销。这些方法控制的是速度、内存、构建成本与召回之间的关系，不能让所有目标同时免费改善。

ANN 的 recall 是“找回精确近邻的比例”，而任务的相关性 recall 是“找回答案相关材料的比例”。一个 ANN 索引可以忠实找回错误 embedding 的最近邻，却在问答上表现很差；也可以丢掉少量精确近邻而未损失任务相关来源。两种指标要分别报告。

## 5. 一个能手算的漏召回例子

数轴上的向量是 a=0、b=0.49、c=0.51、d=1，查询 q=0.505。精确最近的两个点为 c 和 b。如果粗略索引把 0.5 作为分区边界，只访问 q 所在的右半区，就只看到 c 和 d。ANN Recall@2 是 1/2，但第二个候选 d 明显比被遗漏的 b 更远。

增加探测分区能找回 b，但会增加搜索工作。这正是参数扫面的意义：测量多个预算下的召回—延迟曲线，而不是只跑一个点宣布算法更快。实验 `08-ann` 只是粗分区的反例演示，不是 HNSW 实现，也不代表 Faiss 的真实策略。

索引过滤也会改变问题。先在全库选前十再过滤权限，可能剩零个可见结果；可见子集里的真正近邻可能排在全库第一百位。增加 overfetch 只能缓解某些情况，并不能建立严格的授权集合召回保证。课程使用可见子集上的精确搜索作为安全基线。

## 7. 练习与参考答案

**练习 1：精确 top-k。** 以下完整实现接受二维列表，返回距离最近的索引：

```python
def exact_l2(vectors, query, k):
    if k < 0 or any(len(v) != len(query) for v in vectors):
        raise ValueError("invalid dimensions or k")
    distances = [(sum((x-y)**2 for x, y in zip(v, query)), i)
                 for i, v in enumerate(vectors)]
    return [i for _, i in sorted(distances)[:k]]
```

验收：向量 `[[0],[0.49],[0.51],[1]]`、query `[0.505]`、k=2 返回 `[2,1]`；维数不一致应失败，不能靠 zip 静默截断。

**练习 2：存储手算。** 20 万条、1024 维 float16 原始向量需要 `200000*1024*2=409600000` 字节，约 409.6 MB 十进制。再说明 ID、索引和副本不在此数内，不能用它作为整个服务内存上限。

**练习 3：尺度影响。** 用 q=(1,0)，a=(1,0)，b=(10,1)。点积更喜欢 b；余弦 a=1，b≈0.995，因此更喜欢 a。答案证明没有归一化时两者可能排序不同。

**练习 4：模型版本混用。** 文档向量来自旧 embedding，查询来自新版但维数相同，是否可直接切换？答案：不应假设兼容。需双写新索引，重编码并在验证集比较；原子切换查询模型与对应索引，保留回滚版本。

**练习 5：区分两种召回。** 构造精确近邻 A、B，其中只有 C 是答案来源。ANN 找回 A、B，其近邻召回可为 1，任务召回仍为 0。需要改表征或候选策略，继续提高 ANN 搜索预算无法凭空让 C 变近。

**掌握门槛：** 手算余弦与距离，独立实现精确搜索，知道零向量与维数校验，能解释 ANN 近邻召回与答案召回的差别，并在迁移时记录编码器和索引的成对版本。

## 8. 进阶必做：亲手训练一个微型双编码器

到目前为止，词法向量仍无法知道 feline 与 cat 的对应关系。现在直接训练一个小模型，让你看到“语义靠训练形成”在代码里到底是什么意思。运行：

```bash
python -m labs.knowledge.neural_encoder
python -m unittest tests.test_knowledge_neural -v
```

这里只需要 NumPy。程序不下载预训练权重，不使用 API，不占 GPU。训练集只有四对虚构查询与文档：feline pet→cat animal、canine pet→dog animal、key value reuse→cache token、queued jobs→scheduler request。示例会显示损失下降，以及第一条训练查询从错误首位变成正确首位。它证明模型参数能通过监督改变检索空间，**不证明获得了通用语言语义能力**。我们特意输出这个限制，避免把训练集拟合当成泛化。

### 8.1 词表与可学习参数

设词表大小V，向量维数d，参数矩阵E的形状为`[V,d]`。第i行就是第i个词的可学习向量。初始化用固定随机种子和小正态分布。此时 feline 与 cat 的向量没有预先设定的关系；它们接近与否只是随机。

`features(texts)` 把每句话转换为词频平均的行向量X，形状`[batch,V]`。例如句子“red red apple”，red维是2/3，apple维是1/3，其余为0。句子编码就是`X @ E`，等价于对出现词的向量按次数求平均。这个编码器不理解词序，因此“dog bites cat”与“cat bites dog”得到同样向量，这个局限能用一行测试证明。

平均词向量模型不等于Transformer。它没有注意力、位置编码和上下文依赖，无法处理复杂否定与组合语义。但矩阵形状、可学习参数、相似度、损失与反向传播这条链和更复杂模型具有可迁移的结构。

### 8.2 一批正负样本如何构造监督

每一行查询qi与同一行文档di是正对；同一batch其他文档当作负对。查询矩阵Q=`Xq @ E`，文档矩阵D=`Xd @ E`，相似度S=`Q @ D.T / temperature`，形状`[batch,batch]`。对角线表示正对，非对角线表示这次训练中的负对。

“in-batch negatives”不保证所有非对角线都真的不相关。如果两个查询都可以由同一文档回答，把它强行当负例会引入错误监督。真实检索训练需要处理同义问题、重复材料与难负例，本玩具数据通过手工构造减少歧义。

对每行scores做softmax得到候选概率分布P。损失是对正确列的负对数概率取平均，即`L=-mean(log(P[i,i]))`。这里概率表示当前batch内分类分布，不是文档事实真假的概率，也不是整个语料库中答案完整性的概率。

### 8.3 手算二选一的一次损失

假设某查询对两个文档的logits是[2,0]。softmax先减最大值2，得到[0,-2]，指数为[1,0.135335]，归一化得到约[0.880797,0.119203]。如果第一个是正确文档，损失为`-ln(0.880797)≈0.126928`。如果第二个才正确，损失约2.126928。错误而自信会被更重惩罚。

减最大值不改变softmax，因为所有指数共同乘了同一个系数，分子分母约掉。这样可以防止大正数exp溢出。代码直接用稳定log-sum-exp求损失，避免先softmax后log时某个很小概率下溢成0。

temperature缩小会放大logits差异，使分布更尖锐，也会改变梯度尺度。不能把它当生成模型temperature：两者都影响softmax形状，但这里是训练对比目标的参数，不是生成时的采样设置。

### 8.4 反向传播不是神秘的黑箱

令Y为单位矩阵，即正确位置为1，其余为0。对batch平均交叉熵，`dL/dS=(P-Y)/batch`。这意味着正确项的梯度通常为负，梯度下降会提高它；错误项梯度为正，梯度下降会降低它。

由于`S=Q Dᵀ / τ`，矩阵链式法则给出：

```text
grad_Q = grad_S @ D / temperature
grad_D = grad_S.T @ Q / temperature
```

又因为Q=XqE，D=XdE，两个分支共用E，所以参数梯度要把两条贡献相加：

```text
grad_E = Xq.T @ grad_Q + Xd.T @ grad_D
```

这个加号很关键。若只更新查询侧，文档侧仍然通过同一个参数影响损失，却没有被完整计算，梯度就是错的。共享参数的反向传播应汇总所有使用路径，这个思想以后读Transformer权重绑定或多分支计算也会反复出现。

### 8.5 用有限差分证明梯度，而不只看loss下降

错误梯度有时也能让loss暂时下降，所以“训练成功”不是充分验证。选一个参数E[r,c]，分别加上与减去很小ε，重新计算损失，用`(L_plus-L_minus)/(2ε)`近似偏导，再与解析梯度比较。本卷测试选择几个坐标，ε=1e-6，使用float64控制数值误差。

有限差分开销大，不适合验证百万参数全部坐标，但对小模型抽点检查很有用。ε太大会有截断误差，太小则被浮点舍入淹没。测试时还要关闭随机dropout或固定所有随机状态，否则两次损失差异不全来自那个参数。

训练函数使用简单梯度下降，步数250，学习率0.15，并在梯度范数超过5时按比例裁剪。裁剪是限制步长方向的尺度，不是修复错误梯度。课程没有加入复杂优化器，因为当前目标是完整理解参数如何被更新，而不是追求最强效果。

### 8.6 如何证明你没有把拟合误当能力

先打印训练查询排名，再单独提出训练没有出现的词。代码对全未知查询返回空结果，而不会把零向量随便排出的第一文档当答案。对于词表里有词但组合没见过的查询，模型仍可能有得分，但不能保证正确。

至少构造三类评估：训练原句、词序改写、含全新概念的查询。词序改写通过是因为平均池化天然忽略顺序，不是学到了复杂语言理解。新概念失败是模型规模与训练信息不足的合理结果。只有用独立相关性标注集并避免训练数据泄漏，才能谈检索泛化。

**附加练习 A：** 删除共享参数梯度中的文档分支，运行有限差分测试。预期失败；恢复后通过。写出失败坐标与误差，比仅观察loss曲线更能证明你掌握了反向传播。

**附加练习 B：** 把搜索相似度从原始点积改为余弦，重新评测。训练用点积、搜索用余弦不是自动等价；若希望一致，可以在训练中引入归一化并推导其梯度，或明确记录这是一个后处理策略。

**附加练习 C：** 为同一查询添加两个都正确的文档。当前单对角线目标会把另一个正确文档当负样本。参考修正方向是多正例损失，例如分子对所有正例分数求指数和，分母对全部候选求和，再完整推导与测试。不能只复制一行数据后声称训练支持多个正例。

**附加练习 D：** 给编码器加入保存/加载参数的功能。必须同时保存词表顺序、维数、权重、tokenizer版本和训练配置；只保存矩阵而丢掉词到行的映射，加载后会把向量赋给错误的词。加载时校验V与d，拒绝形状不匹配。

这一小模型给你一个真正可修改的学习器。之后阅读Sentence Transformers的encoder、pooling、loss和evaluator时，可以把复杂实现映射回这四个已掌握的对象，而不是只调用encode后把返回的数组当成无法理解的魔法。
