# K05　归约、Softmax、RMSNorm：第一次把数值与并行一起考虑

先修张量、均值、指数和导数基础。归约把一组值合成更少的值；它既是数学操作，也是一棵有执行顺序的计算树。理解这一点，才能正确讨论精度、确定性与性能。

## 1. 归约顺序改变浮点结果

实数加法满足结合律，有限精度浮点加法通常不满足。float32 的 `[1e8,1,-1e8,1]` 按从左到右相加，可能先丢掉第二个 1，再得到 1；成对树形相加可能得到 0；转成 float64 后可得到 2。没有一个结论能简单推广为“并行错误、串行正确”，因为两者都是有限精度算法，误差取决于数据与顺序。

树形归约将长度 N 的数组两两合并，深度约为 `log2(N)`。奇数长度须定义最后一项如何处理。本教材 `tree_sum` 给最后一项配一个零。GPU 实现通常在每个 Block 内做一段，再把 Block 部分结果交给第二次归约。两阶段有额外启动与中间存储，但避免依赖跨 Block 屏障。

```bash
python -m labs.kernels.run --lab 6
```

对比结果并写下使用的数据类型。判断误差要根据用途：求平均统计、训练梯度、top-k 排名与模型逐 Token 输出，对微小差异的敏感程度不同。固定随机种子并不自动固定归约顺序。

## 2. Softmax 为什么先减最大值

Softmax 定义为 `p_i=exp(x_i)/sum_j exp(x_j)`。若 x 为 `[1000,1001,1002]`，直接求指数很容易溢出。令 `m=max(x)`，得到 `exp(x_i-m)/sum exp(x_j-m)`，公共因子 `exp(m)` 被约掉，数学结果相同，指数自变量不大于零。

先手算 `[0,ln2]`：指数为 `[1,2]`，概率为 `[1/3,2/3]`。再把两项同时加 1000，结果不变。这个平移不变性可以做属性测试，比某一个固定输入更能揭示实现问题。

掩码元素应当对分母贡献零。常用做法是在最大值与指数前将无效位置设为负无穷。若整行都被掩码，最大值也为负无穷，直接计算 `-inf-(-inf)` 会产生 NaN。本卷 CPU 参考明确规定：全掩码行输出全零；这个契约未必与每个框架的所有算子一致。GPU 简化 Softmax 只处理没有掩码且每行至少一个有限值的输入，不能把两者能力范围混淆。

## 3. RMSNorm 与 LayerNorm 不一样

RMSNorm 的基本形式是：

\[
y_i=x_i w_i r,\quad r=(\frac1D\sum_j x_j^2+\epsilon)^{-1/2}.
\]

LayerNorm 先减均值，再按中心化方差归一化。对 `[3,4]`，RMS 为 `sqrt(12.5)`，RMSNorm 在单位权重下约为 `[0.8485,1.1314]`；LayerNorm 的中心化结果接近 `[-1,1]`。不能看它们都含 `rsqrt` 就以为可互换。

`epsilon` 防止零或极小分母，其位置是公式的一部分。`1/sqrt(mean(x²)+eps)` 和 `1/(sqrt(mean(x²))+eps)` 不相同。累加 dtype 也很重要：即使输入输出是低精度，平方和常采用更高精度累加。教学参考使用 float64，是为了建立可靠 oracle，而不是模拟生产低精度吞吐。

## 4. 反向传播亲手推

对上游梯度 g，定义 `u_i=g_i w_i`。由于 r 依赖整行的每个 x：

\[
\frac{\partial L}{\partial x_i}=r u_i-x_i r^3\frac1D\sum_j u_j x_j.
\]

第一项来自显式的 `x_i`，第二项来自归一化因子。权重梯度是跨所有行累加 `g_i x_i r`。如果只写 `dx=g*w*r`，等于假装归一化分母与输入无关，前向可能正确但训练会错误。

对 Softmax，有 `dx_i=p_i(g_i-sum_j p_jg_j)`。不需要显式构造 D×D 的 Jacobian；向量公式减少存储和计算。参考实现配套有限差分检查：把一个输入增加和减少微小 eps，估计标量损失的变化。有限差分是数值检查，不是自动证明：步长太小受舍入干扰，太大产生截断误差。

## 5. 练习与参考答案

1. **手算。** 求 `[ln2,ln3,ln5]` 的 Softmax。答案 `[.2,.3,.5]`；把公共平移消掉，再验证总和为一。
2. **故障。** 掩码填零是否等价于不参与 Softmax？答案不等价，`exp(0)=1` 仍贡献分母；在原始 logits 全为负数时尤其明显。
3. **实现。** 给 CPU Softmax 加轴参数测试。参考：保持 `keepdims=True`，分别在 `(2,3,4)` 的最后轴与中间轴上与直接稳定公式比对；不能只测试二维行。
4. **梯度。** 修改 RMSNorm 反向，暂时删除第二项，运行梯度测试。参考答案：有限差分立即暴露差异；解释它对应的链式法则路径，而不是简单把错行改回来。
5. **边界。** 设计零输入、极大值、单元素行、全掩码行、部分掩码行五组测试。验收写明每一组的契约；特别是单元素 Softmax 概率为一，其输入梯度为零。
6. **Kernel 任务。** 阅读 Triton `_rmsnorm`，解释 padding 元素为什么加载零，而归一化分母仍除以 N。答案：补齐只服务执行布局，不改变真实参与平均的元素个数；若除 BLOCK，非二次幂行长度会系统性偏差。

掌握门槛：独立写出稳定 Softmax 和 RMSNorm 前后向；测试能识别掩码、分母、dtype、轴这四类错误；知道结果一致性不等于 bitwise 确定性。
