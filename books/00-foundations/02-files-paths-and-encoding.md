# F02 文件、路径、编码：程序为什么总说“找不到文件”

> 先修 F01。CPU 实验：`python -m labs.foundations.paths`。本章把文件系统的直觉、Shell 操作和 Python 路径处理接起来。

## 1. 文件名、路径、内容是三个不同对象

文件可以先理解成一串字节。文件名是目录中的一个名字，路径是一串定位步骤，内容是读到的字节。`.txt`、`.py`、`.json` 后缀通常帮助人和工具判断用途，但改后缀不会自动转换内容。把图片重命名为 `.py`，Python 不会因此能执行它。

绝对路径从根开始：Linux 下 `/home/learner/course/notes.txt`。相对路径从当前工作目录开始：`notes.txt`、`data/input.json`。`.` 指当前目录，`..` 指父目录。`~` 通常由 Shell 展开为当前用户的家目录；它不是任意程序都自动认识的路径语法。Python `Path("~/notes")` 默认不会展开 `~`，需要 `expanduser()`。

目录也有权限。对普通文件，读权限影响是否能读内容；对目录，执行权限通常决定是否能穿过目录访问里面的名字。知道文件本身可读，仍可能因为父目录不可穿过而无法打开。不要把所有权限错误都用 `chmod 777` 解决，后面会计算权限位。

## 2. 在专用练习目录中练习

从仓库根目录执行：

```bash
mkdir -p .practice/f02/notes
printf '%s\n' 'first line' '第二行' > .practice/f02/notes/example.txt
pwd
ls -l .practice/f02/notes
cat .practice/f02/notes/example.txt
wc -l .practice/f02/notes/example.txt
wc -c .practice/f02/notes/example.txt
```

`mkdir -p` 能创建缺失的父目录；`printf` 把两个字符串各写一行；`>` 是 Shell 重定向，把标准输出写入指定文件。若文件已经存在，`>` 通常会截断原内容。所以创建练习文件必须用专用目录，不能随意向现有配置文件重定向。`>>` 是追加，不会自动判断是否重复添加了同一段配置。

`wc -l` 数的是换行符，不是你在编辑器里肉眼看到的所有“行”。文件最后一行没有换行符时，结果可能比视觉行数少一。`wc -c` 数字节。UTF-8 中常见中文字符通常占三字节，ASCII 字母常占一字节；更广泛 Unicode 字符的长度不能只靠“中文三字节”这个简化规则处理。

## 3. 字节与文本之间的桥：编码

程序读取磁盘时拿到字节，若希望得到 Python 字符串，就要按某个编码解码。写字符串时再按编码编码成字节。可以手算一个例子：`"hello\n学习\n"` 有 9 个 Python 字符，其中 `hello` 是 5 个、两个换行各 1 个、两个汉字各 1 个；UTF-8 字节数是 5+1+6+1=13。

实验输出应包含 `characters: 9`、`bytes: 13` 和两行文本。它在临时目录工作，结束后目录自动清理，所以不会污染仓库。注意 `len(text)` 统计 Python 字符串的码点数量，不保证等于屏幕上的字形数量：组合音标、表情组合等会让“用户感知字符”与码点不同。

```python
text = "学习"
raw = text.encode("utf-8")
assert len(raw) == 6
assert raw.decode("utf-8") == text
```

如果你用错误编码读取一个文件，可能报 `UnicodeDecodeError`，也可能得到乱码但不报错。后一种情况更危险，因为程序似乎能继续。对于自己生成的课程文件，明确写 `encoding="utf-8"`。对外部来源，先确认来源格式；不要默认加 `errors="ignore"` 丢弃坏字节，那会悄悄损坏证据。

## 4. Path 对象怎样组织文件操作

读取 `labs/foundations/paths.py`。`Path` 对象表示路径，但构造 `Path("data")` 不会创建目录。`mkdir` 才创建；`write_text` 才写内容；`exists` 才检查当前状态。区分“描述一个对象”和“执行副作用”很重要，Agent 工具中也应清楚区分规划和动作。

`root / "notes" / "lesson.txt"` 使用 `/` 运算符拼接路径，避免手工处理斜杠。`target.parent` 指父目录；`relative_to(root)` 计算相对表示。`resolve()` 把路径解析成绝对形式，并处理 `..` 与可解析符号链接。

本实验还实现 `contained_path(root, relative)`：拒绝绝对路径；拼接后解析；检查结果是否仍位于 `root` 内。为什么不是简单检查字符串前缀？因为 `/tmp/course-other` 也以 `/tmp/course` 开头；路径边界和文本前缀不是同一问题。

函数的能力边界必须理解：它是一次路径检查，不是操作系统安全沙箱。检查之后若别的进程改变了符号链接，文件操作可能面对不同对象，这叫检查与使用之间的竞态。生产级文件隔离还需要正确的文件描述符操作、权限和进程隔离。基础实验只负责教会你不把 `../` 当成普通文件名。

## 5. 复制、移动、链接与磁盘空间

`cp` 创建内容副本；`mv` 更改位置或名字，在跨文件系统时可能需要复制再删除；符号链接保存另一个路径，并不复制目标内容。硬链接则是同一文件对象的另一个目录名字，不能把它和符号链接混为一谈。

实践时先用 `ls -l` 观察，再操作课程目录内的小文件：

```bash
cp .practice/f02/notes/example.txt .practice/f02/notes/copy.txt
mv .practice/f02/notes/copy.txt .practice/f02/notes/renamed.txt
ls -l .practice/f02/notes
```

大模型权重占用磁盘时，`ls -lh` 看文件逻辑大小，`du -h` 观察实际磁盘占用，`df -h` 查看文件系统可用空间。稀疏文件、压缩、链接或缓存可能让这些数字不完全一致。Git 仓库大小、工作目录大小和一次 push 的传输大小也不是同一个指标：被忽略的权重可能占了很多磁盘，但不在 Git 提交里。

## 6. 文件生命周期与原子替换预告

“打开文件”意味着进程获得访问对象的句柄。删除目录中的名字，并不总能立刻释放所有空间：若进程仍打开该文件，文件内容可能直到最后一个句柄关闭才被回收。你以后排查“日志删了，磁盘还满”时会用到这个模型。

把报告直接写到最终文件时，程序可能中途失败，只留下半份 JSON。更稳妥的模式是在同目录写临时文件，成功后原子替换最终名字。F08 会实现这个过程。此处先理解：保存不是一次神奇动作，而是一系列可能失败的系统调用。

## 7. 六个练习与详细答案

**F02-1 字节题。** 预测 `"A学习\n"` 的 Python 长度和 UTF-8 字节数。验收：写断言验证。答案：码点数 4，字节数 8；分别来自 A 的 1、两汉字的 6、换行的 1。

**F02-2 相对路径题。** 在仓库根目录和 `.practice/f02` 中分别解释 `notes/example.txt`。答案：它们指向不同位置，因为基准工作目录不同。用 `Path.cwd()` 和 `.resolve()` 打印证据。

**F02-3 越界检查。** 给 `contained_path` 输入 `a/../b.txt` 与 `../b.txt`。验收：前者接受，后者拒绝。答案：前者化简仍在根内；后者跳出了根。不能简单禁止所有 `..`，应检查解析后的归属。

**F02-4 编码恢复。** 写入 UTF-8 文件，再分别用 `read_bytes` 与 `read_text` 读取。验收：解释两种返回类型。答案：前者是 `bytes`，后者是 `str`，解码发生在后者中。不要混用 `b"x"` 和 `"x"` 拼接。

**F02-5 最后一个换行。** 创建内容为 `a\nb` 的文件，比较 `wc -l` 与 `splitlines()` 长度。答案：前者为 1，后者为 2。解释你设计的日志格式是否要求每条记录后都有换行。

**F02-6 小文件清单器。** 编写程序输出 `.practice/f02` 下所有普通文件的相对路径和字节数，按路径排序。验收：目录不算文件，输出顺序稳定。参考核心：`for p in sorted(root.rglob("*")): if p.is_file(): ... p.stat().st_size`。拓展：符号链接是否跟随必须作为显式设计选择，而非无意识行为。
