# F14 数学、NumPy与数值：从手算矩阵到能读模型公式

> 先修 F06–F09。实验：`python -m labs.foundations.tensors`、`python -m labs.foundations.numerics`。全部CPU，仅需NumPy。本章不假设你记得大学线性代数。

## 1. 为什么先学形状，再学更复杂公式

标量是一个数，向量是一串按位置排列的数，矩阵是二维排列，张量在此指多维数组。模型代码里的shape是每个轴的长度，dtype是每个元素的数值表示。它们一起约束哪些运算合法、占多少内存。

例如shape=(2,3)可以表示2个token、每个3维特征，也可以表示别的业务轴。shape只告诉尺寸，不告诉语义，所以读代码时要给每个轴写名字。attention里[B,H,T,D]与[B,T,H,D]元素总数相同，含义与布局不同；不看轴顺序就reshape常会造成静默错误。

第一条规则：每写一个矩阵运算，在旁边写输入输出shape。第二条规则：用最小可手算数据验证，别一开始就用随机4096维张量。大张量出错时，你很难知道具体哪一项错。

## 2. 点积是一种加权求和

向量x=[2,3]、w=[4,5]的点积是2×4+3×5=23。可以把w看作每个输入特征的重要性权重。点积结果是标量，输入的对应维度必须一致。

矩阵乘法把许多点积组织在一起。A形状[M,K]，B形状[K,N]，结果C形状[M,N]，其中`C[i,j]=sum_k A[i,k]*B[k,j]`。内侧K相等是因为每个输出都要把A的一行与B的一列配对。

注意逐元素乘法与矩阵乘法不同。在NumPy中`A*B`是逐元素操作（允许广播时也可），`A@B`是矩阵乘法或相应高维规则。把一个符号写错，程序可能仍运行但计算完全不同。

## 3. 手算一个完整线性层

实验输入：

$$
X=\begin{bmatrix}0&1&2\\3&4&5\end{bmatrix},\quad
W=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
b=[10,20].
$$

第一行第一个输出：0×1+1×0+2×1+10=12。
第一行第二个输出：0×0+1×1+2×1+20=23。
第二行分别为3+5+10=18，以及4+5+20=29。

所以Y=[[12,23],[18,29]]。代码`x @ w + bias`把计算表达得很紧凑，但你应能展开成三重循环。只会调用@而不能解释内侧求和，就还没有准备好写GEMM Kernel。

参数矩阵方向取决于库约定。有些线性层把权重存成[out_features,in_features]再转置乘，有些示例存成[in_features,out_features]。看到W.T时先核对shape，不要断言某一方“写反了”。

## 4. 广播是逻辑复制，不是随意自动匹配

Y形状[2,2]，bias形状[2]，相加时按末尾轴对齐，将同一个bias用于每一行。NumPy广播规则从末尾轴比较：尺寸相同，或其中一个是1，通常才可兼容；缺失轴视为1。

例如[3,1]加[1,4]得到[3,4]；[3]加[4]不兼容。广播让代码简洁，也容易产生误解：你本来想按每个样本加一个数，若形状恰巧相等，可能沿错误轴广播却不报错。

练习时刻意让不同轴长度不一样，比如batch=2、sequence=3、features=5；若所有轴都取4，许多轴交换错误会被尺寸巧合掩盖。

## 5. dtype、内存和stride

float64每元素8字节，float32每元素4字节。shape[2,3]的float64数组元素数据总计48字节；对象本身还有元数据，不能把元素数据大小当整个Python进程内存。

stride表示沿某个轴前进一步需要跨多少字节。C连续的[2,3]float64数组通常stride=(24,8)：下一行跨3×8字节，下一列跨8字节。转置视图shape变成[3,2]，stride通常变成(8,24)，并没有立即把所有元素重新排列到一块新内存。

实验打印`np.shares_memory(x,x.T)`为True。视图共享底层数据，修改视图可能影响原数组。reshape有时能返回视图，有时需要复制，取决于布局和请求；不要把所有reshape都当零拷贝。Kernel代码需要理解连续性与stride，否则对转置输入可能读错位置。

## 6. 概率、期望和softmax

一组类别概率p_i应非负且总和为1。期望是按概率加权求和，例如掷公平骰子期望=(1+2+3+4+5+6)/6=3.5；这不意味着骰子某次会掷出3.5。

模型输出logits是任意实数分数，不直接是概率。softmax定义：`p_i=exp(x_i)/sum_j exp(x_j)`。对[0,0]得到[0.5,0.5]。对[0,ln3]得到[1/4,3/4]，可以手算而不用近似。

若logits=[1000,1001,1002]，直接exp可能溢出。减去最大值m后：`exp(x_i-m)/sum exp(x_j-m)`，分子分母都乘以相同exp(-m)，数学结果不变，但数值更稳定。实验结果约[0.090031,0.244728,0.665241]。

不要把“减最大值”理解为删除最大类别信息。它只改变共同偏移，不改变分数差；softmax只依赖相对差异。对所有logits加同一个常数，概率不变，这是很好的性质测试。

## 7. 对数、交叉熵与损失

若真实类别概率为p，负对数损失`-log(p)`会在p接近1时小、接近0时大。比如p=1/2，损失ln2；p=1/4，损失ln4，是前者两倍。这比只看预测类别对错提供更连续的训练信号。

多个样本常取平均损失；平均的分母是有效样本或有效token数，取决于掩码。padding位置不应无意计入分母。不同batch长度下若归一化方式变了，梯度尺度也会变化。这里已经能看出一个“小小求平均”为何会影响模型训练。

稳定计算交叉熵通常直接使用logits与log-sum-exp，而不是先softmax得到极小概率再log。模型卷会实现完整版本；此处先掌握数值变换应保持数学等价，同时改善有限精度行为。

## 8. 导数是局部变化率，梯度是多输入版本

函数f(x)=x²，在x=3附近，x增加很小h时，f变化约6h，所以导数为6。中央差分`[f(x+h)-f(x-h)]/(2h)`可以近似导数，实验h=1e-5得到约6。

h不是越小越好。太大时局部近似误差大，太小时两个近似相等的浮点数相减会放大舍入影响。有限差分适合验证小模型梯度，不适合高维训练时替代自动微分。

链式法则说明复合函数的导数如何相乘。例如y=(2x+1)²，令u=2x+1，则dy/dx=(dy/du)(du/dx)=2u×2。x=3时u=7，导数28。你应能先手算，再用数值差分验证；后续反向传播就是在计算图上系统组织这个规则。

## 9. 浮点不是实数，seed也不是完整复现保证

二进制浮点不能精确表示所有十进制小数，因此0.1+0.2可能不等于0.3的位模式。加法顺序也会影响结果，尤其在大数和小数混合时。并行归约改变顺序，可能导致微小差异；微小logit差异又可能影响采样或argmax边界。

正确性比较应根据数学任务、dtype、误差尺度设置容差；不能一律要求bitwise相同，也不能用宽容差掩盖错误索引。测试整数矩阵时可精确比较，浮点近似算法则要明确误差标准。

随机种子固定随机数生成器的一部分状态，不能自动固定所有库、并行顺序和硬件算法。确定性推理卷会继续讨论；基础阶段先学会记录输入、dtype、形状、实现与环境。

## 11. 数学符号从零读：下标、集合、求和与函数

公式看起来密集，常常只是把普通循环压缩成符号。`x_i` 表示向量 x 的第 i 个分量，下标不是乘法；`x_{i,j}` 表示矩阵第 i 行第 j 列。数学书有时从一编号，Python 通常从零编号，翻译时必须明确。公式里的第一个元素与代码 x[0] 可以对应，但不能机械把所有下标原样复制。

求和符号 `\sum_{i=1}^{n} x_i` 表示把第一项到第 n 项依次相加，等价于初始化 total 为零，再循环加入每项。下标 i 是求和过程的局部占位名字，换成 k 不改变结果；n 是上限，决定项数。看到嵌套求和，就像看到嵌套循环，先确认每个索引在哪个范围变化，哪些量随它改变。

```python
values = [2, 4, 6]
total = 0
for index in range(len(values)):
    total += values[index]
assert total == 12
assert total / len(values) == 4
```

函数 f(x) 表示输入 x 经规则 f 得到结果。括号不是总表示乘法；f(x+h) 是在新输入位置计算函数，不能写成 f(x)+h。参数可以是标量、向量或矩阵，公式旁的类型与形状决定合法操作。模型代码中同一个字母 X 在不同论文可能指不同对象，先看定义而不是凭经验认名字。

实数集合常写作 `\mathbb{R}`，`x\in\mathbb{R}^d` 表示 x 有 d 个实数分量。矩阵 `W\in\mathbb{R}^{d\times m}` 有 d 行 m 列。这个标记只描述数学空间，不说明浮点精度、存储顺序或设备。代码还要补 dtype、stride 和 CPU/GPU 等实现信息，数学对象与内存表示不是同一层。

等号表示两边数学上相等，近似号表示一定条件下近似，定义号表示给名字赋含义。代码中的赋值会改变变量绑定，数学等式通常表达关系；不要把公式 `x=x+1` 当作普通恒等式，它在程序中意味着用旧值计算新值。写梯度下降时可以用 `x_{t+1}=x_t-\eta g_t`，清楚区分更新前后。

## 12. 向量的几何意义：方向、长度与相似性

二维向量可以画成平面中的箭头，分量描述沿两个坐标方向的变化。三维同理，更高维不容易画，但加法和缩放规则仍按分量成立。向量加法把对应分量相加，标量乘法把每个分量乘同一个数。负数缩放改变方向，零倍得到零向量。模型 embedding 也是向量，但每个维度通常不对应一个容易命名的人类概念。

欧氏长度即二范数，定义为各分量平方和再开平方。向量三和四的长度为五，这是勾股定理。平方使负分量也贡献正长度；开平方让单位回到原量尺度。还有一范数等其他度量，选择取决于任务。不要把“范数”只理解成一个库函数名，它表达如何衡量大小。

```python
import math
x = [3.0, 4.0]
norm = math.sqrt(sum(value * value for value in x))
assert norm == 5.0
unit = [value / norm for value in x]
assert unit == [0.6, 0.8]
```

归一化除以长度，得到单位向量。零向量长度为零，不能直接除；实现必须选择拒绝、保留零或使用明确稳定项等策略。添加 epsilon 会改变精确数学结果，应说明为什么以及在哪些范围影响可接受，不能把它当成解决所有数值问题的神奇常量。

点积既是加权和，也与夹角有关：两个非零向量点积等于长度乘积再乘夹角余弦。因此除以两者长度得到余弦相似度。方向相同为一，正交为零，相反为负一。检索中向量是否已归一化，会影响点积与余弦排序的关系；不能看到都在算乘加就认为所有相似度等价。

例如 x=(1,0)，y=(2,0)，z=(0,1)。x 与 y 方向相同，但点积为二，余弦为一；x 与 z 点积零，表示正交。若只用点积，向量长度也影响分数。训练和索引若采用不同归一化合同，检索结果可能变化，这正是基础几何会影响 Agent RAG 实践的具体位置。

## 13. 矩阵作为线性变换与多路加权和

矩阵乘向量可以理解为把输入映射到新坐标。每个输出分量是输入的加权和，权重来自矩阵某一行或列，取决于你选择列向量还是行向量约定。课程使用批量行向量 X 乘 W，单行输入长度 d，W 为 d 乘 m，输出长度 m。其他框架存储权重转置并不矛盾，关键是符号和形状一致。

线性变换满足对加法和缩放的兼容：作用于两个向量之和等于分别作用后相加，作用于缩放输入等于缩放输出。加入偏置后严格说成为仿射变换，因为零输入可能映射到非零偏置。机器学习里常把带偏置层仍称线性层，阅读时要知道术语习惯与数学定义的细微差别。

单位矩阵像乘法中的一，对向量不改变；转置交换行列；矩阵乘法通常不满足交换律。即使 A@B 和 B@A 都合法，结果也可能不同，甚至形状不同。组合变换的顺序有实际意义，例如先旋转再缩放与先做非均匀缩放再旋转不一定一致。模型层堆叠也是有顺序的组合。

```python
import numpy as np
A = np.array([[1., 2.], [0., 1.]])
B = np.array([[2., 0.], [0., 3.]])
assert not np.array_equal(A @ B, B @ A)
assert np.array_equal(A @ np.eye(2), A)
assert np.array_equal((A @ B).T, B.T @ A.T)
```

最后一个转置关系顺序反转：乘积转置等于各矩阵转置后逆序相乘。它不是可以任意交换矩阵的许可，而是由元素索引推导的规则。后续反向传播中出现 W.T，往往与把输出梯度映射回输入维度有关。先掌握形状和这个规则，梯度公式就不会只像符号记忆。

秩描述矩阵能表达多少独立方向。若两列完全相同，输出两路携带重复信息，不能称为两个独立方向。低秩分解用较少中间维度表示某个矩阵，例如 d 乘 r 再乘 r 乘 m；当 r 较小，参数与计算可能减少，但表达能力受限制。LoRA 等方法会利用这种结构，基础阶段先理解“低维中间空间”的含义。

逆矩阵不是每个矩阵都有。方阵也可能因列相关而不可逆；数值上接近不可逆时，求解会放大误差。实际求线性方程通常使用专门求解器，而不是总先显式算逆。对初学者最重要的是知道公式里出现逆需要前提，不能把所有矩阵都当普通非零数来除。

## 14. NumPy 的轴、索引与归约逐步执行

数组 shape 描述每个轴长度，ndim 是轴数量，size 是元素总数。二维数组 shape=(2,3) 有两行三列，size 为六。索引 x[1,2] 选第二行第三列，x[:,1] 选所有行的第二列，冒号表示切片范围。不同索引方式可能返回视图或副本，修改前应明确共享关系。

```python
import numpy as np
x = np.array([[1., 2., 3.], [4., 5., 6.]])
assert x.shape == (2, 3)
assert x[1, 2] == 6
np.testing.assert_array_equal(x[:, 1], [2., 5.])
np.testing.assert_array_equal(x.sum(axis=0), [5., 7., 9.])
np.testing.assert_array_equal(x.sum(axis=1), [6., 15.])
assert x.sum(axis=1, keepdims=True).shape == (2, 1)
```

axis=0 归约第零轴，即把不同行沿这个轴加起来，剩下每列的总和；axis=1 把每行的列加起来，剩下每行总和。初学者常把“沿某轴求和”误读为“保留某轴”，应通过索引展开理解。keepdims 保留被归约轴但长度变为一，便于与原数组广播组合。

例如逐行减均值，行均值应是 shape=(2,1)，这样每一行的一个数广播到该行三列。若直接得到 shape=(2,)，它从末尾对齐，可能不兼容；当原矩阵恰好二乘二时甚至会沿错误方向广播而不报错。刻意使用不相等维度能让这种错误更容易暴露。

reshape 改变观察形状，但不自动交换轴语义；transpose 明确重排轴。将 [batch,time,feature] 直接 reshape 成 [time,batch,feature]，通常不是交换 batch 和 time，而是按内存遍历顺序重新分组。值可能仍连续且程序不报错，但样本和 token 被混合。模型源码里最危险的错误常是这种形状合法但语义错误。

高级索引和布尔索引常产生新数组，与基本切片的共享语义不同。不要仅凭外形短就判断是否零拷贝；使用 shares_memory 观察，并阅读相应接口合同。写算子时还需要理解 stride 和连续性，不能假定传进来的每个数组都是标准连续布局。

## 15. 广播的手算算法与反向归约

判断广播时，从最右侧轴开始比较。两边长度相同可以对齐，其中一边长度为一可以扩展，缺失轴按一理解；其他情况不兼容。结果该轴取较大的长度。这个算法是形状规则，不是根据你想表达“每个样本一个偏置”自动猜业务轴，所以必须先给轴命名。

shape=(2,3,4) 与 (3,1) 对齐为 (2,3,4) 与 (1,3,1)，结果仍为 (2,3,4)。第二个数组在 batch 轴和 feature 轴逻辑复用，实际不必物理复制所有值。shape=(2,3) 则从末尾三对四失败。把两边形状竖着写在纸上，比在代码里不断加 reshape 试错更可靠。

广播还影响梯度。若同一个偏置 b 被加到两行输出，损失对 b 的梯度要把两行贡献相加，而不是随便取一行。这来自同一个变量被多次使用，链式法则需要汇总所有路径。前向看似只是逻辑复制，反向就表现为对复制轴求和。理解这个关系后，框架中的 sum_to_shape 不再是神秘技巧。

```python
import numpy as np
x = np.array([[1., 2., 3.], [4., 5., 6.]])
bias = np.array([10., 20., 30.])
y = x + bias
upstream = np.ones_like(y)
bias_gradient = upstream.sum(axis=0)
np.testing.assert_array_equal(bias_gradient, [2., 2., 2.])
```

本例损失若为所有 y 元素之和，每个 y 的上游梯度是一。每个偏置参与两项，所以梯度为二。若批大小变化，偏置梯度的求和规模也变化；再除以样本数的平均损失会改变尺度。训练代码中 reduction 是 sum 还是 mean，并不是无关参数。

## 16. 概率从事件与频率开始

概率描述事件在模型中的可能性，取值在零到一之间。有限离散结果的概率总和为一，例如公平骰子的六个结果各六分之一。频率是实际重复实验中观察到的比例，它随样本变化；概率是你假设或估计的分布参数。十次实验没有出现某事件，不足以证明其概率为零。

条件概率表示在已知某事件发生时，另一个事件的概率。它改变了可考虑样本的范围。联合概率描述两个条件同时成立，边缘概率通过对其他变量可能性求和得到。独立意味着联合可以分解成各自概率乘积，不是“两个事件听起来没关系”就能直接假设。

一个简单例子：袋中有两颗红球一颗蓝球，不放回抽取。第一次抽红概率三分之二；已知第一次红后，第二次红概率二分之一。两次都红的概率为三分之二乘二分之一，即三分之一。若错误假设独立而乘三分之二两次，会得到四分之九，忽略了第一次抽取改变剩余组成。

贝叶斯公式把“观察在假设下的概率”转换为“观察之后假设的概率”，需要先验与归一化。不要把模型给某个词高概率直接解释为命题真实概率，它只是特定训练与上下文条件下的输出分布。统计建模的事件定义必须清楚，语言模型分数与现实事实可信度不是自动等价。

期望是按概率加权的平均，不一定是某次可能结果。公平骰子期望三点五，但单次不会出现半点。方差衡量围绕期望的平方偏离，标准差再开方回到原单位。两个系统平均延迟相同，方差和尾部可能非常不同，因此平均值不能代表全部用户体验。

```python
values = [1., 2., 3.]
probabilities = [0.25, 0.5, 0.25]
expectation = sum(value * probability for value, probability in zip(values, probabilities))
variance = sum(probability * (value - expectation) ** 2 for value, probability in zip(values, probabilities))
assert expectation == 2.0
assert variance == 0.5
```

这里使用已知离散分布，分母已经包含在概率中；样本方差估计为何可能用 n-1，是另一个估计问题，不能把该修正搬进均值或已知分布方差。F09 故意错误的均值正是提醒你：公式来自具体定义与假设，不能只因见过某个分母就套用。

## 17. 对数、指数与交叉熵的数值路径

指数把实数映射为正数，对数是其反函数。自然对数以 e 为底，满足乘积的对数等于对数之和。概率连乘可能迅速变得极小，取对数后变成相加，既便于计算也便于分析。语言模型一串 token 的条件概率乘积，常用对数概率累加表示，避免直接乘出下溢零。

负对数损失在正确类别概率增大时下降。概率一对应零损失，概率接近零时损失很大。它不仅关心 argmax 是否正确，还关心分配给真实类别多少概率。两个模型都猜对，一个给真实类零点五一，另一个给零点九九，交叉熵可以区分它们的置信分配。

log-sum-exp 计算 `log(sum(exp(x)))`，稳定形式为先减最大值 m，再计算 m 加对数求和。交叉熵对单个真实类别 y 可写为 log-sum-exp 减对应 logit。这样避免先得到下溢为零的概率再取 log。数学等价变形要在有限精度下仔细实现，不能只靠公式正确就忽略中间数值范围。

```python
import numpy as np

def cross_entropy(logits, target):
    x = np.asarray(logits, dtype=np.float64)
    if x.ndim != 1 or x.size == 0 or not np.isfinite(x).all():
        raise ValueError("finite non-empty vector required")
    if type(target) is not int or not 0 <= target < x.size:
        raise ValueError("invalid target")
    maximum = x.max()
    return float(np.log(np.exp(x - maximum).sum()) + (maximum - x[target]))

assert abs(cross_entropy([0., 0.], 0) - np.log(2)) < 1e-12
assert np.isfinite(cross_entropy([1000., 1001., 1002.], 0))
```

这个版本是教学单向量分类损失，不包含 batch、掩码或多标签。扩展时先定义轴与归一化分母，再写代码。把 padding 位置计入平均，或把每条序列平均再对序列平均，都可能与按全部有效 token 平均不同；哪种正确由训练目标决定，必须明确。

## 18. 导数从差商推到规则

导数描述输入在某点发生极小变化时，输出如何变化。差商是输出变化除以输入变化；令步长趋近零得到导数。对平方函数，展开 `(x+h)^2-x^2` 得到二倍 x 乘 h 加 h 平方，除以 h 得二倍 x 加 h，极限为二倍 x。这个推导解释了公式来源，而不是只背幂函数求导表。

导数可以为负，表示局部增加输入会减少输出；为零表示一阶变化不明显，不必然是最小值。平方函数在零处导数零且为最小，立方函数在零处导数也零却不是局部最小。优化时不能只看梯度为零就宣称找到理想解，还要考虑目标形状与约束。

加法求导逐项相加，常数缩放把导数同样缩放，乘积求导需要两项，因为两个因子都随输入变化。链式法则用于复合：外层对中间量的变化率，乘中间量对输入的变化率。把复杂表达式拆成中间变量，是手推与自动微分共同的核心方法。

对 `y=(2x+1)^2`，先令 u=2x+1，再令 y=u²。x=3 时 u=7，外层导数十四，内层导数二，乘得二十八。若只对外层平方求导得到十四，漏掉了输入先被放大两倍的路径。画成计算图后，每条边的局部导数都能检查，避免在长公式中漏项。

有限差分用实际函数值近似导数，中央差分通常比单边差分有更好的局部截断误差，但仍受舍入影响。h 太大不够局部，太小导致相近浮点数相减损失有效位。梯度检查应在多个合理 h 上观察误差趋势，并使用平滑且避开不可导点的小输入，不是把 h 设到极小就认为更准确。

## 19. 偏导、梯度与多条路径的累加

函数有多个输入时，偏导表示暂时固定其他输入，只改变其中一个输入的局部变化率。对 `f(x,y)=x²+3y`，对 x 的偏导为二倍 x，对 y 的偏导为三。梯度把所有偏导按输入顺序组成向量，描述各个坐标方向上的敏感程度。梯度不是一个随意分数列表，每个分量都有对应变量与单位。

在点 (2,4)，梯度为 (4,3)。若小变化为 (h,k)，输出一阶近似变化为四倍 h 加三倍 k，也就是梯度与变化向量的点积。沿负梯度走小步，通常能使可微目标局部下降；步子过大可能跨过低点甚至发散，所以学习率不是越大越好。

```python
import numpy as np

def function(v):
    return v[0] ** 2 + 3 * v[1]

point = np.array([2., 4.])
analytic = np.array([4., 3.])
h = 1e-5
numeric = np.empty_like(point)
for index in range(point.size):
    plus = point.copy()
    minus = point.copy()
    plus[index] += h
    minus[index] -= h
    numeric[index] = (function(plus) - function(minus)) / (2 * h)
np.testing.assert_allclose(numeric, analytic, rtol=1e-8, atol=1e-8)
```

每次只扰动一个坐标，所以得到偏导。plus 和 minus 必须复制，不能与 point 共享同一可变数组后连续修改，否则所谓正负扰动可能互相覆盖。这里 F06 的对象别名知识再次影响数学正确性。数值验证的代码也可能出错，需要小例子与解析结果交叉检查。

若变量经多条路径影响输出，梯度必须累加。对 y=x*x+x，x 同时出现在乘法左输入、右输入和加法支路。x=3 时三条局部贡献为三、三、一，总和七。反向传播若对每条边直接赋值而非累加，最后只留下某条路径，结果错误却可能在没有分支的小图中通过测试。

雅可比矩阵把多输出对多输入的所有偏导组织成矩阵。若输出维度很大，显式保存完整雅可比可能昂贵。反向模式通常计算上游梯度与雅可比的相应乘积，特别适合最终损失是一个标量、参数很多的训练问题。自动微分不是数值差分，也不是符号软件重新推完整公式，而是沿实际计算图组合局部导数。

## 20. 线性层的矩阵梯度从索引推出来

设 X 形状为 n 乘 d，W 为 d 乘 m，b 为 m，输出 Y 为 n 乘 m。每个输出 `Y[i,j]` 是对 k 求和的 `X[i,k]W[k,j]` 加 `b[j]`。现在假设已经知道损失对每个输出的梯度 G，形状同 Y。目标是求损失对 X、W 和 b 的梯度。

固定某个权重 `W[k,j]`，它参与所有样本 i 的第 j 个输出，每条路径贡献是 `X[i,k]G[i,j]`，对 i 求和。把所有 k、j 组织起来就是 `X.T @ G`，形状 d 乘 m。偏置 b[j] 参与所有 i，所以梯度是 G 沿样本轴求和。输入 X[i,k] 则影响该样本所有输出 j，因此梯度是 `G @ W.T`。

这些公式的转置不是背出来的装饰。X.T 把 d 放到行轴，G 保留 m 输出轴，中间共同 n 被求和；W.T 把 m 放到可收缩轴，G 的 n 保留为样本。每个公式输出形状必须与对应变量相同，这是必要检查，但不是充分证明，错误公式有时也可能恰好同形。

```python
import numpy as np
X = np.array([[1., 2.], [3., 4.], [5., 6.]])
W = np.array([[1., -1.], [2., 0.5]])
b = np.array([0.1, 0.2])
G = np.array([[1., 2.], [3., 4.], [5., 6.]])
Y = X @ W + b
dX = G @ W.T
dW = X.T @ G
db = G.sum(axis=0)
assert dX.shape == X.shape
assert dW.shape == W.shape
assert db.shape == b.shape
np.testing.assert_array_equal(db, [9., 12.])
```

为了验证，构造标量损失 `sum(Y*G)`，把 G 当固定上游权重，然后逐个扰动 W 元素，用中央差分比较 dW。不能在数值验证过程中让 G 也随 W 改变，否则验证的函数变了。梯度检查必须清楚哪些是变量、哪些是固定输入，这与实验控制变量原则完全相同。

```python
import numpy as np
X = np.array([[1., 2.], [3., 4.], [5., 6.]])
W = np.array([[1., -1.], [2., 0.5]])
G = np.array([[1., 2.], [3., 4.], [5., 6.]])
def loss(weight):
    return float(np.sum((X @ weight) * G))
expected = X.T @ G
actual = np.zeros_like(W)
h = 1e-5
for index in np.ndindex(W.shape):
    plus, minus = W.copy(), W.copy()
    plus[index] += h
    minus[index] -= h
    actual[index] = (loss(plus) - loss(minus)) / (2 * h)
np.testing.assert_allclose(actual, expected, rtol=1e-8, atol=1e-8)
```

np.ndindex 按形状产生每个索引元组，如 (0,0)、(0,1)，让同一验证循环适用于矩阵。小规模检查可以很慢但清楚；真正训练不能对每个参数运行两次完整前向，因此需要解析反向或自动微分。数值差分是验收工具，不是高维训练的默认算法。

## 21. 梯度下降完整项目：从零拟合一条直线

给定输入一、二、三，目标分别三、五、七，我们希望学习 `prediction=w*x+b`。真实关系是斜率二、截距一，但算法只看到样本。定义残差 prediction 减 target，损失取残差平方和除以二倍样本数。二分之一使求导时平方产生的二抵消，属于简化表达，不改变最优解位置。

初始 w 与 b 都为零，预测全零，残差为负三、负五、负七。损失为八十三除六。对 w 的梯度是残差乘输入再平均，即负三减十减二十一后除三，得到负三十四除三；对 b 的梯度是残差平均，得到负五。学习率零点一时，更新减去负梯度，所以 w 和 b 都增加。

更新必须使用同一时刻计算出的梯度。若先更新 w，再用新 w 重新计算 b 的梯度，你执行的是另一种顺序更新算法，而不是标准同时梯度下降。两者不一定都错误，但不能混淆。在代码中先计算全部梯度，再更新参数，最容易与手算对应。

```python
import numpy as np
x = np.array([1., 2., 3.])
y = np.array([3., 5., 7.])
w, b = 0.0, 0.0
learning_rate = 0.1
losses = []
for step in range(2000):
    prediction = w * x + b
    residual = prediction - y
    loss = float(np.mean(residual ** 2) / 2)
    grad_w = float(np.mean(residual * x))
    grad_b = float(np.mean(residual))
    losses.append(loss)
    w -= learning_rate * grad_w
    b -= learning_rate * grad_b
assert losses[-1] < losses[0]
np.testing.assert_allclose([w, b], [2., 1.], rtol=1e-6, atol=1e-6)
```

每轮前向计算预测，损失衡量误差，反向计算梯度，优化步骤更新参数。这四个阶段就是训练循环的最小骨架，后续大模型虽然数据与参数多得多，仍需要这套清楚边界。优化器、混合精度和分布式并不会消除基本数学关系。

先把迭代次数改成一，核对手算参数；再改成十观察下降；最后运行完整迭代检查接近真实关系。不要一上来跑两千次只看最终成功，因为中间某个错误可能被特定数据巧合掩盖。换一组已知斜率截距的合成数据，再验证算法是否仍能学习，可以检查是否硬编码了答案。

学习率过大可能振荡或发散，过小则收敛慢。输入尺度也影响梯度大小：若 x 放大一千倍，原学习率未必适用。标准化与优化器设计因此有实际意义。训练失败时先检查输入尺度、损失定义、梯度和更新符号，不要立即增加层数或更换复杂框架。

def dot(left, right):
    if len(left) != len(right):
        raise ValueError("same length required")
    total = 0

### 二：三重循环矩阵乘法

```python
import numpy as np

def matmul(left, right):
    left, right = np.asarray(left), np.asarray(right)
    if left.ndim != 2 or right.ndim != 2 or left.shape[1] != right.shape[0]:
        raise ValueError("compatible matrices required")
    output = np.zeros((left.shape[0], right.shape[1]), dtype=np.float64)
    for row in range(left.shape[0]):
        for column in range(right.shape[1]):
            for inner in range(left.shape[1]):
                output[row, column] += left[row, inner] * right[inner, column]
    return output
X = np.array([[0., 1., 2.], [3., 4., 5.]])
W = np.array([[1., 0.], [0., 1.], [1., 1.]])
np.testing.assert_array_equal(matmul(X, W), [[2., 3.], [8., 9.]])
```

最内层 inner 对应公式求和索引，每个输出先为零再累加。把初始化放进错误循环层会丢掉先前贡献，测试应使用多个非零项而不是只有单位矩阵。

平移不变检验相对分数性质，有限性检验稳定实现，总和检验概率归一化。三者互补，不能只检查输出长度正确。

### 七：零向量不能盲目归一化

```python
import numpy as np

def normalize(vector):
    x = np.asarray(vector, dtype=np.float64)
    if x.ndim != 1 or not np.isfinite(x).all():
        raise ValueError("finite vector required")
    norm = np.linalg.norm(x)
    if norm == 0:
        raise ValueError("zero vector has no direction")
    return x / norm
np.testing.assert_allclose(normalize([3., 4.]), [0.6, 0.8])
try:
    normalize([0., 0.])
except ValueError:
    pass
else:
    raise AssertionError("zero direction must fail")
```

本题选择拒绝零向量，其他业务可选择不同合同，但必须明确。不要让零除产生 NaN 后继续进入相似度排序。

### 八：链式法则与差分

```python
from labs.foundations.numerics import finite_difference
function = lambda x: (2 * x + 1) ** 2
actual = finite_difference(function, 3.0)
assert abs(actual - 28.0) < 1e-6
```

解析导数是外层二倍中间量再乘内层二，不能漏掉后者。误差阈值适合当前小函数与默认步长，不代表所有函数都用同一容差。

### 九：概率期望不必是可能结果

```python
values = [1, 2, 3, 4, 5, 6]
probability = 1 / 6
expectation = sum(value * probability for value in values)
assert abs(expectation - 3.5) < 1e-12
assert expectation not in values
```

期望描述分布平均，不是预测下一次必然出现的点。用平均延迟代表每个请求耗时也犯了类似概念混淆。

### 十：分支梯度累加

```python
from labs.foundations.numerics import finite_difference
x = 3.0
grad_left_product = x
grad_right_product = x
grad_direct_add = 1.0
analytic = grad_left_product + grad_right_product + grad_direct_add
numeric = finite_difference(lambda value: value * value + value, x)
assert analytic == 7.0
assert abs(numeric - analytic) < 1e-6
```

三条路径属于同一个输入变量，必须相加。自动微分实现中累加梯度的原因在这个例子里已经完整出现。

### 十一：softmax 加交叉熵的 logit 梯度

```python
import numpy as np
from labs.foundations.numerics import softmax
logits = np.array([0., np.log(3.)])
target = np.array([0., 1.])
gradient = softmax(logits) - target
np.testing.assert_allclose(gradient, [0.25, -0.25], atol=1e-12)
assert abs(gradient.sum()) < 1e-12
```

对正确类别的梯度为负，梯度下降会提高它的 logit；错误类别为正，更新会降低它。梯度和为零与共同平移不影响损失相呼应，但这里只适用于当前标准单标签交叉熵合同。

### 十二：检查一次线性回归更新

```python
import numpy as np
x = np.array([1., 2., 3.])
y = np.array([3., 5., 7.])
w, b = 0.0, 0.0
residual = w * x + b - y
grad_w, grad_b = np.mean(residual * x), np.mean(residual)
np.testing.assert_allclose([grad_w, grad_b], [-34 / 3, -5])
w -= 0.1 * grad_w
b -= 0.1 * grad_b
np.testing.assert_allclose([w, b], [34 / 30, 0.5])
```

这个单步验收比只看最后拟合正确更容易定位更新符号和分母错误。完整训练应该在单步正确之后再扩展迭代。

## 23. 四个数值故障现场

**矩阵形状合法但输出错位。** 检查轴语义和 reshape/transpose 区别，用不同轴长度与带位置编码的小整数样例观察。随机同方阵常隐藏交换错误。先手算一个输出元素，再核对对应输入行列，不要直接放宽误差阈值。

**softmax 出现 NaN。** 检查输入是否有限、是否直接 exp 大数、是否全被掩码成负无穷以及归一化分母是否为零。减最大值解决有限大 logits 的溢出，不自动解决所有掩码与非有限输入。当前函数明确拒绝非有限值，所以不能直接拿它处理全负无穷掩码而期待合理概率。

**梯度差分不一致。** 先检查解析公式、输入拷贝、固定上游梯度与更新时机，再试合理步长。若函数在检查点不可导，例如绝对值零点，中央差分可能给出一个值却不代表唯一导数。梯度检查应选择平滑区域，并说明不可导点的约定。

**训练损失变大。** 检查梯度下降是否写成加梯度，是否遗漏平均分母，输入尺度是否改变，学习率是否过大。打印有限的损失与梯度范数，先用两三个样本手算。不要把爆炸简单归咎于模型太小或数据太少，基础代数错误往往更直接。

## 24. 从本章连接模型与算子代码

Transformer 的线性投影是批量矩阵乘法，注意力分数是点积，softmax 把分数转成权重，输出是对 value 的加权和；归一化涉及均值、方差与广播；训练通过链式法则把标量损失传回参数。你现在已经具备理解这些部件的基本数学语言，下一步应逐个手写而不是只记名称。

算子实现还要把数学索引映射到内存地址。shape 告诉你逻辑坐标，stride 告诉你相邻坐标跨多少字节，dtype 决定元素表示。转置视图、切片和广播都可能改变访问方式而不改变数学目标。先用 CPU 三重循环解释每个输出，再到 Triton 或 CUDA 分配线程和 tile，会更容易判断错误属于数学还是地址计算。

本章的完整验收是一份手算线性层、一份 NumPy 对照、一份矩阵梯度差分检查与一条能拟合合成直线的训练曲线。它们各自证明前向、形状、反向与优化循环的一部分。不要用最终损失下降替代所有中间验证，也不要用一条小直线拟合成功宣称已经掌握大模型训练的全部问题。

## 25. 概率的第二轮手算：条件、贝叶斯与信息量

设两台机器生产零件，甲生产七成、乙生产三成；甲的次品率百分之一，乙的次品率百分之四。随机拿到次品后，来自乙的概率不是百分之四，也不是三成。先算“来自乙且次品”的联合概率，为零点三乘零点零四，得到零点零一二；全部次品概率为零点七乘零点零一加零点三乘零点零四，得到零点零一九；条件概率是二者相除，约零点六三二。

这个例子说明先验比例与观察概率共同影响后验。某证据在某假设下比较常见，不意味着观察到证据后该假设概率就等于那个似然。检索评分、分类器输出和现实结论之间也需要明确建模关系，不能把一个模型给出的分数自动解释成经过校准的真实概率。

信息量常用负对数概率表达：越不常见的事件，观察到时带来的信息量越大。对数底决定单位，以二为底常用 bit，自然对数常用 nat。熵是对信息量取期望，描述分布的不确定程度。公平二分类比几乎确定的二分类熵更大，因为前者结果更难预测。

交叉熵用真实分布的权重评价模型分布的负对数概率。若真实标签为 one-hot，它简化成真实类别的负对数概率；若标签是软分布，就需要对所有类别加权求和。KL 散度比较两个分布的差异，通常不对称，所以不能把它当普通几何距离。它们与概率、对数和期望相连，不是互不相关的损失函数名称。

在离散分布中，真实分布对某事件赋正概率，而模型给零概率，会产生无限负对数惩罚。有限精度计算可能把非常小概率舍入到零，这也是直接从 logits 稳定计算损失的重要原因。随意给概率加一个较大 epsilon 虽能避免报错，却改变目标，必须说明影响范围。

采样与取最大值也不同。argmax 总选最高分项，采样按概率随机选择；概率零点六并不意味着每次都选该项。temperature 等操作改变分布尖锐程度，随后再采样。固定随机种子只能帮助复现某个生成器在相同流程下的选择，不改变分布本身，也不保证远端服务每次完全相同。

## 26. 从 softmax 导数推到交叉熵梯度

设 p_i 是第 i 类 softmax 概率，分母 Z 是所有指数之和。对某个 logit x_j 求偏导，需要同时考虑分子和分母。i 等于 j 时，分子也随 x_j 改变；i 不等于 j 时，分子不变但分母改变。最终可以统一写成 `p_i(δ_ij-p_j)`，其中 δ 在 i=j 时为一，否则为零。

这个雅可比包含非对角项，说明提高一个类别分数不仅改变自己的概率，也改变其他类别，因为总和必须为一。不能把 softmax 当作每个元素独立的 sigmoid。模型实现若错误地逐元素处理导数，可能在某些简单样例上看似合理，却不满足归一化耦合关系。

对真实类别 y 的损失是负 log p_y。链式法则把损失对概率的导数，与概率对 logits 的导数组合后，得到每类梯度 `p_j - 1[j=y]`。因此正确类别梯度为概率减一，其余类别梯度为自身概率。梯度下降减去这个梯度，会提高正确类别相对分数，降低其他类别相对分数。

手算两类 logits 为零和 ln3，概率四分之一与四分之三，真实类是第二类。梯度为四分之一与负四分之一，和为零。共同给 logits 增加常数不改变概率，所以损失沿全一方向的导数为零；梯度和为零正对应这一不变性。数学性质与测试断言可以这样相互解释。

若损失对 batch 求平均，还要除以有效样本数；若某些 token 被 mask，分母与参与梯度的集合必须一致。把每条序列的平均再平均，会让短序列与长序列拥有相同序列权重；把所有有效 token 一起平均，则每个 token 权重相同。两种目标不同，不能在训练中无意切换后仍认为梯度尺度与数据权重没变。

## 27. 连续变化、积分与数值近似的基础直觉

导数关心局部变化率，积分可以理解为把许多小贡献累加。例如速度随时间变化，某小段时间的位移约为速度乘时间长度，把所有小段相加便近似总位移；小段越来越细时得到积分。它与求和有相似结构，但连续变量需要考虑区间与极限，不是简单把离散下标换个符号。

连续概率分布用密度描述，某区间概率是密度在区间上的面积。密度值本身可以大于一，只要总面积为一；因此不能像离散概率那样要求每个密度数都不超过一。单个精确点在连续分布下通常概率为零，并不表示附近事件不可能发生。区分概率与密度有助于以后理解高斯分布和扩散模型公式。

正态分布由均值与方差等参数描述常见钟形密度，均值决定中心，标准差决定尺度。标准化减去均值再除标准差，使数据按共同尺度表达；这不会自动让任意数据变成正态分布。模型里的 LayerNorm 也不是“把数据变成高斯”，它主要按指定轴调整均值与尺度，并可能再做可学习仿射变换。

数值积分、有限差分和矩阵计算都体现同一个原则：数学连续对象需要有限表示与有限步骤近似。误差来自离散化、截断、舍入与输入本身的不确定性。把所有误差都称为“浮点误差”会妨碍定位；例如网格太粗是近似误差，错误轴求和是程序错误，两者不该靠同一容差处理。

## 28. 浮点范围、精度与累加顺序

浮点格式用有限位数表示符号、指数和有效数字。指数范围决定能表示多大多小，有效位数决定相近数之间能分辨多细。float16、float32、float64 在范围与精度上不同，某些低精度格式还采用不同分配。不能只按字节数推断所有数值性质，也不能认为位数减半就一定速度翻倍。

大数与小数相加时，小变化可能小于当前数值间距而被舍入掉。随后再减去大数，小数不会自动回来。因此加法顺序会影响结果，数学上的结合律在有限精度里不一定逐位成立。并行归约改变分组方式，可能产生微小差异；这不是许可任意大误差，而是要求根据任务与 dtype 选择合理验收。

```python
left = (1e16 + 1.0) - 1e16
right = 1e16 + (1.0 - 1e16)
assert left == 0.0
assert right == 0.0
recoverable = (1e16 - 1e16) + 1.0
assert recoverable == 1.0
```

这个例子用一组明确可观察的括号顺序展示小量被舍入。不要从中得出“浮点不能用”的结论；应选择稳定算法、合适精度与独立误差检查。大规模求和可以使用更稳定的归约方法或更高精度累积，但要评估性能与任务需要。

上溢通常产生无穷，下溢可能产生很小的数或零，非法运算可能产生 NaN。输入有限也不保证所有中间结果有限，例如 exp 很大的有限数。稳定 softmax 通过平移避免不必要上溢；归一化中的小方差则需要审查分母。每种稳定化手段针对具体数值结构，不应该到处随意加 epsilon。

梯度检查建议使用 float64 和小规模输入，因为它减少舍入噪声，让数学错误更容易暴露；正式低精度训练仍要单独检查其误差与范围。参考实现与目标实现可以使用不同精度，但必须说明比较标准。只有形状正确和结果有限还不够，还要与手算或可信参考比较。

## 29. 一张数学到代码的自查表

读到求和，找到对应循环或 reduction 轴；读到点积，确认两个向量长度与配对顺序；读到矩阵乘法，写出收缩轴和保留轴；读到广播，标出哪些维度逻辑复用；读到梯度，确认上游形状、局部导数和多路径累加；读到平均损失，确认分母究竟数什么。每项都能回到具体代码，而不是停留在术语记忆。

自己的解答还应包含一个不满足前提的反例：零向量归一化、空均值、形状不兼容、非有限 logits、不可导点差分、过大学习率。反例让你知道公式在哪些条件下成立，也让实现能给出明确失败。数学学习的扎实程度不只体现在会算正常例子，还体现在能指出公式前提和数值边界。

当你能独立推导线性层梯度、解释 softmax 的耦合、手算一次训练更新，并把每个数组轴标上含义，就可以开始模型卷的完整 Transformer 实现。未来遇到 MoE 路由、稀疏结构和线性注意力时，仍然用同样方法：先定义数学对象与形状，再手算最小例子，最后写参考实现和梯度或数值验收。

### 补充：缩放与平移不是同一变换

softmax 对所有 logits 加同一个常数不变，但乘同一个正数通常会改变概率。把差异放大，分布更集中；把差异缩小，分布更平缓。temperature 常通过除以正温度实现这种尺度调整，所以它与减最大值的稳定化不是同一目的。前者改变采样分布，后者在数学上保持分布不变。

点积注意力中的缩放也需要从统计尺度理解。若向量分量在某些简化假设下具有相近方差，很多乘积项求和后尺度随维度增长；适当缩放可以避免分数过大使 softmax 过度集中。具体模型分布未必严格满足简化假设，但这个推导提供设计直觉。不要把某个缩放因子当作无需理解的固定符号。

### 补充：掩码平均的完整手算

设两条序列有效 token 数分别为一和三，第一条损失为四，第二条三个损失都是一。先按序列平均再平均，得到四与一的平均，即二点五；把全部四个有效 token 一起平均，得到七除四，即一点七五。两种数字都能正确反映各自定义，但不能互相声称完全等价。

如果 padding 位置补零后直接对完整矩阵 mean，还会把无效位置算进分母，使损失随补齐长度变化。正确实现应先明确哪些位置有效，再计算分子和有效计数；有效计数为零时要定义拒绝或其他明确策略，不能让零除产生 NaN 后继续训练。这个基础边界在真实语言模型训练中十分常见。

### 补充：学习率实验的证据

比较不同学习率时，保持初始参数、数据顺序、损失定义和迭代次数一致，再观察损失曲线与最终误差。若同时改变输入尺度和初始化，无法把结果变化单独归因于学习率。记录每轮或适当间隔的损失即可，不必打印全部大数组；一份小而清楚的实验表，比只写“这个参数效果最好”更能支持理解。

每次推导完成后，都用一个能手算的小输入交叉验证符号与代码；数学等式、数组形状和实际数值三者一致，才算完成这一轮学习。
