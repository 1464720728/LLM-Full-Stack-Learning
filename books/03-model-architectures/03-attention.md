# M03　把 Attention 从公式变成能逐项检查的程序

[本卷导航](README.md) · 前置：[M02](02-gradients-training.md) · 下一章：[原始 Transformer](04-original-transformer.md)

Attention 不是“模型自动抓重点”这句话的另一个名字。它是一套具体计算：产生查询与键，计算两两相似度，归一化为权重，再混合值。本章先把一次计算手算完整，再讨论遮罩、数值、梯度和多头。实验为 NumPy CPU，没有隐藏的 fused attention 调用。

## 1. 为什么要把输入投影成 Q、K、V

设某个 token 的隐藏向量为 x。模型可以用不同线性变换得到 `q=xWq`、`k=xWk`、`v=xWv`。q 决定当前读取什么，k 决定当前记录以什么特征被匹配，v 决定记录被读取后提供什么信息。三者不是三个不同 token，也不是从数据库里预先提取的字段；它们是可训练投影产生的数值。

一个类比是查表：查询和索引特征用于定位，结果内容用于读取。但真实注意力一般不是只查一行，而是根据相似度把多行内容加权合成。不要把这个类比推进到“每个 attention head 存储固定数据库字段”；实际表示没有这种强制语义分工。

单头数学式为：

$$ S=\frac{QK^\top}{\sqrt{d_k}},\quad P=\operatorname{softmax}(S+M),\quad O=PV. $$

Q 的形状 `(Tq,dk)`，K 为 `(Tk,dk)`，V 为 `(Tk,dv)`。Q 与 K 通道数必须相同才能点积，V 的通道数却可以不同。输出是 `(Tq,dv)`。自注意力常有 Tq=Tk，但交叉注意力完全可以不相等。

## 2. 一次可手算的因果注意力

取 `Q=K=[[1,0],[0,1]]`，`V=[[10,0],[0,20]]`，dk=2。未遮罩 scores 为：

$$ \begin{bmatrix}0.7071&0\\0&0.7071\end{bmatrix}. $$

因果 mask 不允许第一个位置看第二个位置，所以第一行变成 `[0.7071,-∞]`，softmax 为 `[1,0]`，输出 `[10,0]`。第二行可以读两个位置，其权重约为 `[0.3302,0.6698]`，输出约为 `[3.3024,13.3952]`。

每一个数都能对应代码：`q @ k.T` 产生分数矩阵；除以 `sqrt(2)`；`np.where(mask,scores,-np.inf)` 切断非法连接；`softmax` 沿 key 轴归一化；再右乘 V。如果沿 query 轴归一化，列和为 1、行和未必为 1，已经是另一种函数。

运行 `python -m labs.models.run_lab attention`，先对照第一行，再对照第二行。不要只观察最后输出“看起来合理”。从中间量入手，才能定位 mask、缩放或矩阵方向的错误。

## 3. 缩放与 softmax 稳定性

若 q、k 的各分量近似独立、均值 0、方差 1，那么 dk 项乘积相加的方差约为 dk，标准差约为 √dk。直接把维度很大的点积送入 softmax，可能使分布非常尖锐、梯度变小。除以 √dk 是调整输入尺度的方法。这个推导依赖理想化统计假设，不表示所有训练后 Q/K 都严格满足独立同分布。

softmax 对所有 logit 加同一常数不变，因此可以先减最大值防止指数溢出。`exp(1000)` 会溢出，而 `exp(1000-1001)` 不会。稳定算法改变的是计算路径，数学函数仍相同，但浮点舍入不必逐 bit 相同。

“整行都被遮掉”需要明确定义。直接对 `[-∞,-∞]` 减最大值会出现 `-∞-(-∞)=NaN`。本卷选择输出零行，表示没有可读值；并写测试防止 NaN。其他框架对全遮罩行可能有不同约定或依赖 kernel 版本，所以迁移实现必须核查，不要暗中假定所有软件一致。

## 4. 因果性、padding 和位置偏移

因果性要求位置 i 的输出只依赖 `0..i`。因此可以用一个反事实测试：改动最后一个 token 的 V，前面所有位置输出必须不变。这比检查 mask 长得像三角形更有意义，因为真正执行的广播方向也可能错。

带 KV cache 时，query 可能只有一行，但 key 有很多行。此时 `tril(1,Tk)` 只允许看第一列，是错误的。当前 query 的绝对位置如果为 20，它应允许看 key 位置 0 到 20。正确条件是 `key_position <= query_absolute_position`。本卷把 offset 显式传进 mask 构造，避免把矩阵行号误当全局 token 位置。

Padding mask 则阻止真实 token 去读取补齐位置。训练可同时需要 causal mask 和 padding mask，两者通常做逻辑与。有些 API 的布尔 True 表示允许，有些表示屏蔽；本卷统一 True=允许。阅读框架源码时第一件事就是确认这一语义，而不是照搬变量名 `attn_mask`。

## 5. 多头意味着并行子空间，不是重复同一公式几次

设隐藏宽度 D=8、H=2，每头 dk=4。Wq 先把输入投影到 8 个通道，再分为两个头。每头独立计算 `(T,T)` 权重，两个输出按通道拼接，再乘 Wo 混合。不同头可以学习不同匹配模式，但不能保证“第一头负责语法，第二头负责事实”。

多头 attention 的概率矩阵常是 `(B,H,Tq,Tk)`。MHA 的 K/V 头数与 Q 一样；GQA/MQA 会减少 K/V 头数，本卷后面单独实现。它们不是把 H 个头平均成一个，而是改变投影与共享关系。

注意 attention 不是全部 Transformer：它通常还与归一化、残差和逐位置 MLP 交替。只实现注意力无法直接替代语言模型，因为 token embedding、位置、输出头和训练目标还没连起来。

## 6. 从矩阵反向推到算子优化

前向需要 `QKᵀ`、softmax、`PV`。若显式物化 P，要保存约 T² 个数；T=4096 时单头就有约 1678 万个位置，float32 约 64 MiB，尚未计 Q/K/V、其他头与反向中间量。这个估算指朴素实现，不是所有 optimized attention 的必需内存。

FlashAttention 的核心学习意义是：在不改变标准 softmax attention 数学目标的前提下，重排分块计算与在线归一化，避免完整物化大矩阵。稀疏 attention 则改变允许的连接，通常会改变函数。前者是计算方式优化，后者是模型算子定义的变化。后续比较必须区分“相同函数更高效”和“另一个函数具有不同成本”。

本卷用朴素版作为正确性 oracle。先把 q/k/v、mask 和精度固定，再比较优化版输出及梯度。不能用两组随机权重的输出差异评价 kernel 正确性。

## 7. 练习与参考解

1. **取消 mask。** 手算第一行新输出。答案：第一行权重约 `[0.6698,0.3302]`，输出 `[6.6976,6.6048]`；说明未来值进入了当前输出。
2. **统一平移。** 在每行 scores 上加 123，验证结果不变。答案：指数公共因子在分子分母抵消；只给某一列加常数则会改变权重。
3. **全遮罩行。** 给三行 mask 的第二行全部 False。验收：第二行输出零，不出现 NaN，其他行保持原结果。参考：归一化除法必须有 `where=total>0`，不能只在结果上把 NaN 改成零掩盖其他错误。
4. **缓存 mask。** q_len=2、k_len=7、offset=5，画出允许关系。答案：第一行允许 0..5，第二行允许 0..6。若返回左上角两个三角行则是位置错误。
5. **变 V 不变 Q/K。** 将 V 乘 2。验收：概率矩阵不变、输出恰好乘 2。这是分离寻址与内容的测试。若 weights 变了，代码中混用了 V。
6. **写朴素双循环版。** 不用矩阵乘法计算每个 score，再计算输出。参考：三层循环分别覆盖 query、key、channel；与向量化版误差小于 `1e-10`。这不是性能实现，却能训练你检查 index 的能力。
7. **设计梯度检查。** 把最后输出的平方和当损失，分别对 Q/K/V 小矩阵做差分。验收：未来 mask 上的相应影响应消失；计算全部差分慢但小维度足够。下一步在 PyTorch 用自动微分与自己的局部公式交叉检查。

本章通过标准：能从空白文件写出稳定 attention，能说明每条测试针对哪类 bug，能解释为什么缓存后的三角 mask 需要偏移。
