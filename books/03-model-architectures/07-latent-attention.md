# M07　低秩、矩阵吸收与 MLA：把缓存的对象换掉

[本卷导航](README.md) · 前置：[M06](06-kv-gqa.md) · 下一章：[MoE](08-moe.md)

这一章不要求你直接实现某个旗舰模型的完整 MLA。它要求你先亲手验证一个严谨的代数等价：当 K/V 都从共同低维表示投影而来时，可以改变计算结合顺序，减少必须保存的对象。然后你才能读懂真实 MLA 中哪些额外机制让事情变复杂。

## 1. 低秩不是“把小数位砍掉”

量化减少每个数的编码位数，低秩分解改变表示所需的数的数量。一个 `(D,D)` 矩阵若写为 `(D,r)@(r,D)`，参数量从 D² 变为 2Dr。当 r 远小于 D 时可能节省参数，但不能保证任意矩阵都可精确低秩表示。

若矩阵原本就是两个小矩阵的乘积，则这种表示是模型定义的一部分，不是部署时临时近似。若训练后对任意矩阵做截断 SVD，则通常引入近似误差。区分“从头以低秩参数化训练”和“事后低秩压缩”，类似区分原生量化训练与事后量化。

手算矩阵 `[[1,2],[2,4]]` 的第二行是第一行的 2 倍，秩为 1，可以写为列 `[1,2]ᵀ` 乘行 `[1,2]`。矩阵 `[[1,0],[0,1]]` 秩为 2，不能用单个外积精确表示。

## 2. 共同 latent 的完整代数

设历史压缩状态 `C:(T,r)`，上投影 `Uk:(r,dk)`、`Uv:(r,dv)`。定义 `K=C Uk`、`V=C Uv`。标准 attention 的分数是：

$$ QK^\top=Q(CU_k)^\top=(QU_k^\top)C^\top. $$

因此可以先把当前 Q 投影到 r 维，再直接与历史 C 比较。权重 P 得到以后：

$$ PV=P(CU_v)=(PC)U_v. $$

这里两次只是改变矩阵乘法结合顺序，在实数数学下精确等价。它并没有把 softmax 移过线性变换，也没有声称 `softmax(AB)=softmax(A)softmax(B)`，后者一般是错的。

最容易漏掉的是缩放因子：原始 score 除以 √dk。吸收后 query 的维度变成 r，但为了计算同一函数，仍然必须除以 √dk，不能因为当前矩阵形状就改成 √r。测试专门用 dk=6、r=2，避免维度偶然相同掩盖错误。

## 3. 缓存与计算各省在哪里

若 T=1000、dk=dv=64、r=16，显式保存 K/V 需要 `1000*(64+64)=128000` 个元素；保存 C 需要 16000 个，理论元素数减少 8 倍。实际模型还可能需要位置分量、多个头或 scale，因此这是当前 toy 定义下的精确计数，不是某真实模型的显存承诺。

计算方面，吸收后的 query 投影可能变贵或变便宜，取决于头数、rank、batch 和是否能预合并权重。对于 prefill，大矩阵路径与 decode 的单 token 路径可能采用不同实现。不能只看“少保存几个数”就断言总性能一定提升。

若进一步把输出投影 Wo 与 Uv 合并，可能减少中间结果物化；但多头拼接、共享 latent 和不同维度的具体布局都会影响合法的合并方式。读框架代码中 `absorb`、`einsum`、`latent cache` 等名字时，要把每个矩阵形状写下来验证。

## 4. 为什么 RoPE 让简单吸收复杂化

假设每个历史位置都有不同旋转 R_t，则位置编码后的 key 是 `(c_t Uk) R_t`。R_t 依赖 t，通常不能把一个固定 Uk 简单吸收到 query 并对所有位置复用。矩阵乘法顺序也不能随意交换：一般 `Uk R_t` 不等于 `R_t Uk`，维度甚至未必允许。

真实 MLA 的设计会处理内容通道与位置通道的关系，例如解耦位置分量。本卷不在未逐项核对官方代码时把一个无 RoPE 的低秩 toy 宣称为完整 MLA。`latent_attention` 的 docstring 明确写出这个边界。

这个边界不是让你停在高层，而是一个可执行的读源码任务：先在官方模型实现中定位低秩下投影、上投影、Q/K 位置分支；再追踪 cache 真正保存哪些张量；最后分别手算内容 score 与位置 score。你已经会验证基本代数，才能识别官方实现中新增了什么。

## 5. 用误差定位公式错误

运行 `python -m labs.models.run_lab mla`。代码用同一 q、C、Uk、Uv 比较显式 K/V attention 和吸收形式，最大误差应接近 float64 舍入量级。它没有分别随机生成两套参数，因此比较有意义。

故障一：把 √dk 改成 √r。输出仍有限、维度仍正确，但概率锐度改变。故障二：把 `Uk.T` 漏掉，若测试尺寸恰巧方阵，代码可能仍能运行而结果错误。故障三：把 softmax 放到 `Q@Uk.T` 之后，改变了函数。故障四：在 mask 前做归一化然后简单乘零，剩下权重总和小于 1，输出幅度改变。

你应训练自己用中间量定位：先比较 scores，再比较 P，再比较 output。若 scores 一致、output 不一致，问题在 value 或输出投影；若只有被遮罩位置不同，检查 mask；若全局锐度差异，检查缩放。

## 6. 低秩和 LoRA 的关系与区别

LoRA 常写成 `W'=W+(α/r)AB`，其中 W 保留，AB 是低秩增量。它减少需要训练的增量参数，但不自动改变原 attention 的 KV 状态契约。MLA 类低秩缓存结构则在模型前向中定义了低维历史表示。两者都出现低秩矩阵，却解决不同问题。

本卷提供 `lora` 函数和合并等价测试，供后训练章使用。若将 LoRA 合并回 W，推理时可能无需额外两段矩阵乘，但结果取决于 dtype 与量化处理。若保持 adapter 独立，方便多 adapter 切换，却增加调度和计算路径。把这种区别写进实验报告比背“LoRA 节省显存”更重要。

## 7. 练习与参考解

1. **手算外积。** 用 `[1,2]ᵀ@[3,4]` 得到 `[[3,4],[6,8]]`。列出秩≤1 的证据。答案：每行互为倍数，非零矩阵秩恰为1。
2. **缩放故障。** 修改 r 与 dk 不相等的实验，验证错除 √r 后误差明显。答案：改变 softmax 温度等价地改变分布，不能用输出投影补偿全部输入。
3. **参数和状态账本。** T=4096、dk=128、dv=64、r=32，元素数分别为 786432 与 131072，压缩比6。再给每 token 增加16维位置状态，新压缩比变为4。要求解释附加状态为何不能忽略。
4. **无因果 mask 验证。** 同时取消两种形式 mask，等价关系仍应成立。参考：mask 与低秩代数是独立维度，测试两者组合能避免只覆盖一个特殊路径。
5. **非低秩随机 K/V。** 先生成自由 K/V，再强行选很小 r 做近似。参考：通常不能精确重建，比较的是压缩误差而非代数实现误差；不应要求同一严格阈值。
6. **官方 MLA 读图。** 阅读来源表 S04 的 DeepSeek-V3 原始报告/代码，交付 Q 内容维、Q 位置维、KV latent、位置 cache 四条形状关系。不要先下载所有权重。参考完成标准：每个符号对应具体投影/切分代码；未核对的维度标记待查，禁止凭另一模型配置填空。

通过标准：能自己推导并实现吸收公式，能解释它为什么保持函数，也能说清真实位置编码会破坏哪些过于简单的重排假设。
