# M10　线性注意力与 Delta 记忆：从历史列表到固定状态

[本卷导航](README.md) · 前置：[M03](03-attention.md)、[M06](06-kv-gqa.md) · 下一章：[状态空间模型](11-state-space.md)

这里的“线性”通常描述随序列长度的计算复杂度，而不是说整个模型只含线性函数。线性注意力仍可以有非线性特征映射、门控、归一化和复杂投影。它与 softmax attention 一般是不同的算子，不应把二者输出不一样当作实现错误。

## 1. 为什么 softmax 不容易直接重结合

标准注意力使用 `softmax(QKᵀ)V`。矩阵乘法结合律允许 `(QKᵀ)V=Q(KᵀV)`，但中间有按行 softmax，不能直接把它删掉或移到别处。线性注意力构造一种可分解的相似度：`sim(q,k)=φ(q)ᵀφ(k)`，其中 φ 是特征映射。

为保持正权重与可解释的归一化，可选正值映射。本卷用 `ELU(x)+1`：x≥0 时为 x+1，x<0 时为 exp(x)。它不是 softmax kernel 的精确恒等变换，而是一个独立定义的 kernel attention。

因果输出定义为：

$$ y_t=\frac{\sum_{i\le t}(\phi(q_t)^\top\phi(k_i))v_i}{\sum_{i\le t}\phi(q_t)^\top\phi(k_i)}. $$

## 2. 固定维度状态从哪里来

把求和顺序换一下：

$$ S_t=\sum_{i\le t}\phi(k_i)v_i^\top,\quad z_t=\sum_{i\le t}\phi(k_i), $$
$$ y_t=\frac{\phi(q_t)^\top S_t}{\phi(q_t)^\top z_t}. $$

若 φ 输出 dk 维、v 为 dv 维，S 是 `(dk,dv)`，z 是 `(dk,)`。每来一个 token，就加一个外积并更新 z。状态大小不随 T 增长，但每 token 更新成本包含 dk×dv，不能简单说“常数状态所以零成本”。

手算一维：φ(k1)=2、v1=3，第一步 S=6、z=2；再来 φ(k2)=1、v2=9，S=15、z=3。任意正 query 标量 q 的输出为 `q*15/(q*3)=5`。在一维时 q 约掉，说明状态表达能力受到特征维度限制；多维才有不同查询方向。

标准 KV cache 保留各条记录，理论上可逐条寻址；固定矩阵状态把历史压缩成统计量，不保证还能恢复每条原始记录。长上下文不等于无限精确记忆。架构选择必须结合任务：高精度引用、排序、拷贝和检索可能对历史保真度有不同要求。

## 3. 三种实现，必须算同一函数

`linear_attention_dense` 先显式构造 kernel scores，加因果 mask，归一化后乘 V。`linear_attention_recurrent` 按 token 更新 S/z。第三种是把输入切两块，第一块返回最终状态，第二块从该状态继续。

它们应在浮点容差内相同。完整并行与递推之间的微小差异可来自求和顺序，不代表公式不等价。若差异很大，常见原因是状态在计算输出之前还是之后更新：本卷定义包含当前 token，因此先写入当前 k/v，再用当前 q 读取。

数值契约也必须一致。本卷两种实现对任何正分母直接相除，分母因下溢成为零时返回零行；没有只在递推版额外添加epsilon或最小值截断。例：q=k=-350时ELU+1约为exp(-350)，分母约exp(-700)，虽极小仍大于零；若value=1，正确归一化结果仍为1。把分母强行夹到1e-300会改变函数，破坏等价性。输入Q/K/V与beta/decay的序列长度必须显式相同，不能依靠zip静默截断较长序列。测试覆盖极小正分母、真正下溢与长度不匹配。

这与某些只读取过去、随后写入当前记录的记忆机制不同。两者都可能合理，但必须与训练定义一致。不要仅靠循环顺序“看起来像 RNN”就认定实现正确。

## 4. 为什么需要遗忘与选择

简单加法状态会不断累积，旧记录与新记录可能相互干扰。引入衰减 `S_t=α_t S_{t-1}+k_t v_tᵀ` 可以控制旧信息保留。α 接近1保留更久，接近0快速遗忘；若是逐通道 gate，不同维度可以有不同时间尺度。

衰减并不等于“模型主动删除无用记忆”的完整解释。它是由网络输入和参数产生的数值门，训练决定其倾向。要观察实际效果，需要具体序列实验，例如写入一个关联、插入干扰、再次查询，测输出随间隔与 gate 的变化。

Delta rule 更进一步：先读取当前 key 对应的预测，再只写入误差。以本卷 S 的方向为 `(dk,dv)`：

$$ \tilde S_t=\alpha_t S_{t-1},\quad e_t=v_t-k_t^\top\tilde S_t, $$
$$ S_t=\tilde S_t+\beta_t k_t e_t^\top,\quad y_t=q_t^\top S_t. $$

若 key 是单位向量、β=1，同一个 key 的再次写入可以覆盖旧关联，而普通外积累加会把新旧值相加。用 k=[1,0]，先写3再写7，实验输出3、7；这是理解“纠错式写入”的最短数值例子。

## 5. Key 范数为什么重要

若没有单位范数约束，β=1 并不保证精准覆盖。因为写入后重新读取会多出 `kᵀk` 的比例。选择 normalize、控制 β 或改变 update 公式都是定义的一部分。真实 gated delta/KDA 系统还包括投影、短卷积、归一化、输出门与高效 chunk scan；本卷的 `delta_recurrence` 只是核心状态更新，不宣称与真实权重兼容。

同样，固定状态不意味着能随意丢弃序列顺序。带 gate 或 delta 的更新通常不交换：先写A后写B，与先写B后写A产生不同状态。需要并行化时必须找到满足结合规则的更大状态表示或分块算法，不能简单把所有外积求和。

## 6. 资源与正确性的两套实验

```bash
python -m labs.models.run_lab linear
python -m labs.models.run_lab delta
python -m labs.models.compare
```

先验证 dense kernel attention 与 recurrent 等价；再算状态元素数。设 dk=dv=8，S/z 总元素64+8=72，而标准单头 KV 在 T=24 时元素为384。但如果 dk=dv=128，状态是16512个元素，短序列标准 KV 可能更小。固定不等于总是最小。

性能实验要区分预填充和逐步生成，也要固定 dtype 和硬件。Python 递推可能慢于 NumPy 大矩阵计算，不能由此否定线性 attention 的 GPU 算法；同样不能从大 O 直接宣称任意长度都快。

## 7. 练习与参考解

1. **一维手算。** 令三个映射后的 key 为1、2、1，value 为2、4、8，最后输出 `(2+8+8)/4=4.5`。要求同时用显式权重与状态法算出相同结果。
2. **块式状态。** 在第4个 token 切开长度11的序列。验收：两次 recurrent 拼接与一次完整 recurrent 一致；第二段不得重置 z，也不能修改调用方传入旧 state 的数组。
3. **更新顺序故障。** 把输出计算移到当前写入前。参考：第一个输出使用空状态，且之后每步少看当前记录；这是另一种时序，不满足本章定义。
4. **遗忘实验。** 写入1后连续输入0，α=.5，观察状态1、.5、.25…；α=1则保持。答案必须区分写入项是否也为零，不能只把输入变零却让 bias 仍产生新写入。
5. **Delta 覆盖。** 单位 key 先写3再写7，β=.5，第二次读到5；β=1读到7。若 key 改为 `[2,0]`，解释为何不能直接沿用覆盖结论。
6. **状态大小交叉点。** dk=dv=64，线性状态4160元素，标准KV每token128元素，约T=33时后者超过前者。参考：这是元素计数，不计scale、层混合或数据布局，不是性能交叉点。
7. **真实实现拓展。** 阅读 Kimi Linear/KDA 或其他官方 gated delta 实现，逐项标出本 toy 缺少的投影、卷积、gate、normalization、chunk算法。先复现核心等价性，再修改一个组件；不要把官方 kernel 的输入直接喂给未对齐的toy就解释误差。

通过标准：你能从公式推导固定状态递推，能实现 chunk continuation，并能用单位 key 数值例子解释 delta 写入与简单加法的区别。
